logic.py

Checks: LOGIC: The truth values property; LOGIC: The meadow property; LOGIC: The defect theorem; LOGIC: The Kleene reading theorem; LOGIC: The pair theorem; LOGIC: The envelope theorem; LOGIC: The envelope's sharpness theorem; LOGIC: The ladder theorem; LOGIC: The order-6 shadow theorem; LOGIC: The ladder's reach property.

Cited on: LOGIC.

To run it: save logic.py; standard library only.

"""logic.py -- the logic a squarefree ring's own polynomials carry.

QUESTION. Take a squarefree modulus M with prime set S and the ring
Z/M, a product of the prime fields F_p, p in S (the CRT). Its
IDEMPOTENTS are the residues reading 0 or 1 on every channel, one per
subset T of S, written 1_T. The four ring polynomials
    AND(a, b) = ab,   OR(a, b) = a + b - ab,
    NOT(a) = 1 - a,   IMP(a, b) = 1 - a + ab
are the Boolean connectives on the idempotents. What do the same
polynomials do on the rest of the ring, what can a reader who applies
only ring operations decide about a residue's truth, and where does
that reader stop?

THE ARGUMENT (written before this script). Every map built from ring
operations acts channel by channel, so every statement below is a
statement about one prime field F_p, lifted by the CRT.
  (1) THE TRUTH VALUES. A residue with a^2 = a reads 0 or 1 on every
      channel, since F_p has no other idempotent, so the idempotents of
      Z/M are the 2^|S| tuples 1_T; at a prime-power factor Z/q the
      only idempotents are still 0 and 1 (e(e - 1) = 0 with e and
      e - 1 coprime), so any modulus N has 2^omega(N) of them. The map
      n -> an is multiplicative iff a^2 xy = a xy for all x, y, which
      at x = y = 1 is a^2 = a: the multiplicative self-maps of Z/M of
      the form n -> an are exactly the idempotents. A product 1_T u
      with u a unit is a unit only if 1_T is, so only 1 = 1_S keeps
      any unit a unit. The MASS of T, #{x : x 1_T = x} / M, counts the
      residues vanishing off T: prod over T of p, over M, which is
      1 / prod of the primes outside T; so
      mass(T and U) mass(T or U) = mass(T) mass(U).
  (2) THE MEADOW. Z/M is von Neumann regular (every a has an x with
      axa = a) iff M is squarefree: on a field take x = a^(-1) or 0;
      at a factor Z/q with q = p^r, r >= 2, the residue p has
      p x p = p only if p(px - 1) = 0 mod p^r, and px - 1 is a unit, so
      p = 0 mod p^r, false. The regular residues of Z/q are exactly 0
      and the units. The PSEUDO-INVERSE a' inverts each nonzero
      channel and keeps each zero; the SUPPORT supp(a) is the set of
      channels where a is nonzero. Channel by channel: aa' = 1_supp(a),
      a'' = a, supp(a') = supp(a), supp(ab) = supp(ab') = supp(a) and
      supp(b); supp(a + b) contains the symmetric difference of the
      two supports and lies in their union; and (ab')b = a iff
      supp(a) lies in supp(b).
  (3) THE DEFECT. Write delta(a) = a^2 - a; delta(a) vanishes on
      channel p iff a reads 0 or 1 there. A Boolean law built from the
      four connectives holds on {0, 1}^n in Z, so LHS - RHS is a
      polynomial vanishing on {0, 1}^n; its multilinear reduction mod
      x_i^2 - x_i is then zero, so LHS - RHS lies in the ideal
      generated by the delta(x_i). Ten charted laws each carry a
      one-variable factor:
        a AND a - a = delta(a)          a OR a - a = -delta(a)
        (a IMP a) - 1 = delta(a)        (a OR NOT a) - 1 = delta(a)
        a AND NOT a = -delta(a)
        a AND (a OR b) - a = delta(a)(1 - b)
        a OR (a AND b) - a = -delta(a) b
        a AND (b OR c) - ((a AND b) OR (a AND c)) = delta(a) bc
        a OR (b AND c) - ((a OR b) AND (a OR c))
                                 = -delta(a)(1 - b)(1 - c)
        a AND (a IMP b) - (a AND b) = -delta(a)(1 - b)
      and contraposition, both De Morgan laws and double negation hold
      as polynomial identities. The defect composes:
        delta(NOT a) = delta(a),
        delta(ab) = delta(a) delta(b) + delta(a) b + a delta(b),
        delta(a + b) = delta(a) + delta(b) + 2ab,
      each by expansion. OR and IMP are NOT-conjugates of AND, so by
      induction supp(delta(F)) lies in the union of the leaves'
      defect supports for every formula F in the four connectives,
      while bare + creates defect (delta(1 + 1) = 2). A non-classical
      x (x not 0 or 1 in F_p) becomes classical under AND with exactly
      two partners, 0 and x^(-1) (xy in {0, 1}); under OR with exactly
      1 and 1 - (1 - x)^(-1), by conjugation; under NOT never. And
      a AND a = a is a^2 = a, so the relation "a AND b = a" is not
      even reflexive off the idempotents: the graded region has no
      order, and its degrees are LOCATED by channel, never ranked.
  (4) THE KLEENE SHADOW. Read a channel as T (1), F (0) or U (anything
      else). If one input is classical the connective's output class
      is strong Kleene's: AND with 0 is 0 and with 1 is the other
      input; OR dually; IMP with a = 0 or b = 1 is 1, with a = 1 it
      is b, with b = 0 it is NOT a. If both inputs are U, Kleene says
      U and the ring departs exactly when the output lands on 1 or 0:
      ab = 1 (b = a^(-1), itself U), a + b - ab = 0, i.e.
      (1 - a)(1 - b) = 1, and 1 - a + ab = 0, i.e. a(1 - b) = 1; each
      picks one partner per a, so p - 2 departures among the (p - 2)^2
      unknown pairs, per binary connective. NOT never departs.
  (5) THE PAIR. With lambda = lcm(p - 1) over S, DIA(a) = a^lambda
      reads [a != 0] per channel and BOX(a) = 1 - (1 - a)^lambda reads
      [a = 1]; both land on the idempotents. DIA(NOT a) = NOT BOX(a)
      by definition. DIA(ab) = DIA a AND DIA b because F_p has no zero
      divisors; BOX(a OR b) = BOX a OR BOX b because
      (1 - a)(1 - b) = 0 iff a = 1 or b = 1. On the dual connective
      each leaks one way: DIA(a OR b) < DIA a OR DIA b exactly when
      a, b != 0 and (1 - a)(1 - b) = 1, which is p - 2 of the
      (p - 1)^2 pairs of nonzero inputs; BOX(a AND b) > BOX a AND
      BOX b exactly when ab = 1 with a != 1, also p - 2 pairs, and
      (a, b) -> (1 - a, 1 - b) carries the first set onto the second.
      So DIA can lose truth over OR and never create it. The gap
      DIA a - BOX a is DIA(delta(a)) = DIA a AND DIA(NOT a): the
      channels read "true to some degree and false to some degree"
      are the defect's support. The monadic laws BOX a AND a = BOX a,
      DIA a AND a = a, DIA and BOX idempotent and fixing each other's
      outputs, BOX(a IMP b) AND BOX a <= BOX b, and
      DIA(a AND DIA b) = DIA a AND DIA b hold channel by channel.
      THE WALL: once |S| >= 2 no polynomial computes [a = 0]; a
      polynomial's channel-p value depends on a mod p only, and a = 0
      and a = 1_(S minus p) agree at p while [a = 0] reads 1 and 0.
  (6) THE ENVELOPE. Push NOT to the leaves (De Morgan is an
      identity). Per leaf keep only the two bits DIA a and BOX a; let
      the ROOF U evaluate the AND/OR tree in Boolean logic with DIA a
      at a positive leaf and NOT BOX a at a negated one, the FLOOR L
      with BOX a and NOT DIA a. Then channel by channel
          L <= BOX F <= DIA F <= U
      by induction: at a literal the conjugacy makes both ends exact;
      at AND, DIA is exact and BOX only gains; at OR, BOX is exact and
      DIA only loses; so the two leak directions are the two
      inequality slots. U = 0 certifies F false, L = 1 fully true.
      On a channel where every leaf is classical, U = L = F.
      SHARPNESS, read-once. Record a formula by (value set, U, L), the
      value set being every value F takes over inputs with its leaves'
      measured bits. The leaves of a read-once formula are independent,
      so AND and OR combine value sets as a product. The leaf classes
      are {0}, {1} and the graded set G = F_p minus {0, 1}, with bits
      (0, 0), (1, 1), (1, 0), and NOT permutes them. For p >= 5,
      |G| = p - 2 > (p - 1)/2, so for each unit t the sets G and tG^-1
      meet: G*G = F_p^*, and by conjugation G OR G = F_p minus {1}.
      Every record with (U, L) = (1, 0) contains G (AND with {1} and OR
      with {0} keep a record, AND with {0} and OR with {1} send it to
      {0} or {1}), so a product of two such holds F_p^*, and 0 iff a
      factor does. The closure is six records: {0}, {1}, and (X, 1, 0)
      for X = G, F_p^*, F_p minus {1}, F_p. Each is achieved, since a
      (1, 0) set holds a graded value, neither 0 nor 1. So at p >= 5
      every read-once formula of any size reaches both ends. At p = 3,
      G = {-1}, G*G = {1} and G OR G = {0}: forced, the rigidity.
      Repeated leaves break it at every p >= 3: the (p - 1)-fold AND of
      a leaf is a^(p - 1), 1 at every graded input, so at a graded leaf
      the floor 0 is never reached, and its OR dual misses the roof.
      (Checked after the record below, as V3.)
  (7) THE LADDER. For m dividing lambda let G_m(a) = BOX(a^m): per
      channel it reads [a^m = 1], i.e. a != 0 and ord(a) | m. G_1 = BOX
      and G_lambda = DIA; m | d gives G_m <= G_d; G_gcd(m, d) =
      G_m AND G_d, since ord | m and ord | d iff ord | gcd. The join
      G_m OR G_d equals G_lcm(m, d) iff on EVERY CHANNEL each divisor
      of p - 1 that divides the lcm divides m or d; the ring's own
      orders do not decide it (2 has order 12 in Z/35, yet there
      G_4 OR G_6 = G_12, channel 5 holding orders 1, 2, 4 and channel 7
      orders 1, 2, 3, 6). The least lcm that can leak is lcm(2, 3) = 6,
      and it leaks exactly when a channel has p = 1 mod 3. The power
      map x -> x^r has prod over S of (1 + gcd(r - 1, p - 1)) fixed
      points (0, or x^(r-1) = 1 in a cyclic group of order p - 1).
      The map x -> x^j is idempotent on Z/M iff x^(j^2) = x^j for all
      x, iff j^2 = j mod lambda (taking j in 1..lambda): 2^omega(lambda)
      such maps, the idempotents of Z/lambda.
  (8) THE ORDER-6 SHADOW. BOX(a AND NOT a) reads [a(1 - a) = 1] =
      [a^2 - a + 1 = 0] = [Phi_6(a) = 0]. For p > 3 the roots of Phi_6
      in F_p are the elements of order 6, present iff 6 | p - 1, i.e.
      p = 1 mod 3 (the primes splitting in Q(zeta_6)); at p = 2 there
      is none; at p = 3, Phi_6 = (x + 1)^2, one double root -1 of
      order 2 (3 ramifies: Phi_6's discriminant is -3). Every graded
      residue has the pair bits (1, 0), so the pair decides this
      shadow on a channel iff the shadow is constant on the graded
      residues: at p = 1 mod 3 it is not (order-6 elements read 1,
      others 0); at p = 2 mod 3 it is constantly 0; at p = 3 the graded
      region is the single point -1, which reads 1. The ladder reads
      it as G_6 AND NOT(G_2 OR G_3) at every p but the point -1 of
      p = 3, where gcd(6, p - 1) = 2 folds G_6 onto G_2. The pair does
      not pin that point, since -1 at p = 5 carries the same bits; the
      pin G_2(a) AND NOT BOX(a) AND G_2(NOT a) does, a = -1 with
      NOT a = 2 of order at most 2, which is p = 3, so the ladder
      formula OR the pin reads the shadow at every channel. (Checked
      after the record below, as L4's third line.)
  (9) THE LADDER'S REACH. A one-leaf reader applying the ladder to a
      and to NOT a sees exactly the pair (ord a, ord(1 - a)), 0 read as
      order 0. A shadow that is not a function of that pair escapes it,
      and two inputs with equal pairs and unequal shadows prove the
      escape. Two leaves: [ab = 1] depends on the relation between a
      and b, which no pair of one-leaf profiles holds.

DESIGN. Seven sections of checks printing PASS or FAIL; per channel
the checks run over every residue (or pair, or triple) of F_p for the
primes stated, and a ring-level sample through the CRT checks the
lifting on Z/2310, Z/510510 and the non-rung Z/1001 = 7 * 11 * 13.
  E  the truth values. The idempotent count against 2^omega(M) for
     every M in 2..3000, squarefree or not; the multiplicative maps
     n -> an against the idempotents over the full grid of x, y for
     every M <= 40; the unit test at Z/2310; the mass of all 32 T at
     Z/2310 by counting, and the product law over all pairs.
  M  the meadow. Regularity by search for every M in 2..200 against
     squarefreeness; the regular residues of every prime power
     q = p^r <= 400, r >= 2, against {0} and the units. POSITIVE
     CONTROL: the search must find a non-regular residue at M = 12.
     Then the pseudo-inverse laws over all of Z/2310, and the support
     laws over every pair of Z/210 and 20,000 pairs of Z/510510.
  C  the connectives and the defect. Boolean on the 32 idempotents of
     Z/2310, the residuation law (x AND a) <= b iff x <= (a IMP b)
     over all 32^3 triples. The ten deformations and the four
     identities over every triple of F_p, p <= 13, and of Z/30. The
     three composition laws over every pair of F_p, p <= 23. No
     creation over 5,000 random formulas to depth 4 on Z/510510, each
     leaf classical on an odd channel with probability 0.85 (on 2
     always), a formula's defect support read against the union over
     the leaves it reads; CONTROL first: the same detector must see
     bare + create defect, 1 + 1 from the classical leaf 1. The AND and
     OR partners of every
     non-classical x, p <= 23, as sets. Reflexivity fails exactly off
     the idempotents of Z/2310.
  K  the Kleene shadow. Every pair of F_p, p <= 23, every connective:
     mismatches with a classical input, and departures among U-U
     pairs. POSITIVE CONTROL: at p = 2 the two tables agree on every
     pair.
  Q  the pair, per channel over every residue and pair, p <= 23 (the
     channel exponent is p - 1, which lambda is a multiple of), and
     20,000 ring samples on Z/510510 and Z/1001. The wall by its
     witness at Z/30; that a polynomial is channel-local is the wall's
     proof and is not run.
  V  the envelope, by CLOSURE. Every leaf is a record (value, U, L,
     classical); AND and OR act on records; the set of records
     reachable from the leaves of F_p is closed under both, so the
     sandwich checked on the closure holds for every NNF formula of
     any size, repeated leaves included (the check is per input).
     p <= 23. Then SHARPNESS for read-once formulas, by CLOSURE too: a
     record is (value set, U, L), a leaf's value set being all
     residues of its measured class, and read-once AND/OR combine the
     sets as an independent product; the envelope is ACHIEVED when
     U = 1 implies a nonzero value in the set and L = 0 a value other
     than 1. The fixpoint under both operations holds every read-once
     formula's record, at every prime 3 <= p <= 97, and is compared
     with the six records the argument names. POSITIVE CONTROL: p = 3.
  L  the ladder, on every residue of the seven channels of Z/510510
     for every m | 240 (its lambda, a multiple of each p - 1 there):
     G_m against [ord | m], the ends, monotony, meet-exactness, the
     least defective lcm over all divisor pairs; G_2 OR G_3 against G_6
     at every p <= 199; on 3000 samples of Z/510510, the 20 gates
     distinct as maps. The fixed-point count
     over all of Z/M for M in {30, 210, 1001, 2310}, r in 2..30. The
     idempotent power maps over all of Z/2310 (lambda 60) and
     Z/1001 (lambda 60), j in 1..60. The order-6 shadow at every
     p <= 199; the pair's blindness per p <= 199; the ladder formula
     at every (p, x), p <= 23, and the pin's support at every
     p <= 199. The reach: the first p <= 100 where
     [a^2(1 - a) = 1] is not a function of (ord a, ord(1 - a)), and
     CONTROL: Phi_6's shadow never is; the [ab = 1] witness at p = 7.

  E  2^omega(M) with no exception over M = 2..3000; the maps n -> an

import random
from itertools import product
from math import gcd, prod

CHECKS = []


def check(name, ok, detail=""):
    CHECKS.append(bool(ok))
    print(f"  [{'PASS' if ok else 'FAIL'}] {name}"
          + (f" -- {detail}" if detail else ""))


def is_prime(n):
    return n > 1 and all(n % d for d in range(2, int(n ** 0.5) + 1))


PRIMES = [p for p in range(2, 400) if is_prime(p)]
ODD23 = [p for p in PRIMES if 3 <= p <= 23]


def prime_factors(n):
    out, d = {}, 2
    while d * d <= n:
        while n % d == 0:
            out[d] = out.get(d, 0) + 1
            n //= d
        d += 1
    if n > 1:
        out[n] = out.get(n, 0) + 1
    return out


def squarefree(n):
    return all(e == 1 for e in prime_factors(n).values())


def lam(M):
    out = 1
    for p in prime_factors(M):
        out = out * (p - 1) // gcd(out, p - 1)
    return out


# The connectives, on Z/M for any M.
def AND(a, b, M): return a * b % M
def OR(a, b, M): return (a + b - a * b) % M
def NOT(a, M): return (1 - a) % M
def IMP(a, b, M): return (1 - a + a * b) % M
def delta(a, M): return (a * a - a) % M
def DIA(a, M, L): return pow(a, L, M)
def BOX(a, M, L): return (1 - pow((1 - a) % M, L, M)) % M


def supp(a, S):
    return frozenset(p for p in S if a % p)


def idem(T, S, M):
    """1_T: the residue reading 1 on T and 0 on the rest of S."""
    x = 0
    for p in S:
        if p in T:
            q = M // p
            x += q * pow(q, -1, p)
    return x % M


def pinv(a, S, M):
    """The pseudo-inverse: invert each nonzero channel, keep each zero."""
    x = 0
    for p in S:
        r = a % p
        if r:
            q = M // p
            x += pow(r, -1, p) * q * pow(q, -1, p)
    return x % M


def order(x, p):
    if x % p == 0:
        return 0
    k, y = 1, x % p
    while y != 1:

def random_formula(rng, leaves, depth):
    if depth == 0 or rng.random() < 0.3:
        return ("leaf", rng.randrange(leaves))
    op = rng.choice(("AND", "OR", "NOT", "IMP"))
    if op == "NOT":
        return (op, random_formula(rng, leaves, depth - 1))
    return (op, random_formula(rng, leaves, depth - 1),
            random_formula(rng, leaves, depth - 1))


def leaves(f):
    if f[0] == "leaf":
        return {f[1]}
    return set().union(*(leaves(g) for g in f[1:]))


def evaluate(f, xs, M):
    if f[0] == "leaf":
        return xs[f[1]]
    if f[0] == "NOT":
        return NOT(evaluate(f[1], xs, M), M)
    a, b = evaluate(f[1], xs, M), evaluate(f[2], xs, M)
    return {"AND": AND, "OR": OR, "IMP": IMP}[f[0]](a, b, M)

def k3(op, x, y):
    """Strong Kleene on classes 0 (F), 1 (T), None (U)."""
    if op == "NOT":
        return None if x is None else 1 - x
    if op == "AND":
        if x == 0 or y == 0:
            return 0
        return 1 if (x, y) == (1, 1) else None
    if op == "OR":
        if x == 1 or y == 1:
            return 1
        return 0 if (x, y) == (0, 0) else None
    return k3("OR", k3("NOT", x, None), y)          # IMP

def env_leaf(p, v, neg):
    """A leaf record (value, U, L, classical) for the literal at value v."""
    L = p - 1
    d, b = int(DIA(v, p, L) == 1), int(BOX(v, p, L) == 1)
    val = NOT(v, p) if neg else v
    U, Lo = (1 - b, 1 - d) if neg else (d, b)
    return (val, U, Lo, v in (0, 1))


def env_combine(r, s, op, p):
    if op == "AND":
        return (r[0] * s[0] % p, r[1] & s[1], r[2] & s[2], r[3] and s[3])
    return (OR(r[0], s[0], p), r[1] | s[1], r[2] | s[2], r[3] and s[3])
