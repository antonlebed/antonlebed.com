three fates keep when the least move is softened into a Boltzmann
choice, over Z and over F_2[x].

QUESTION. growth.py grows a state Z/M by the LEAST multiplier m >= 2
that a demand admits. Soften the least into a weight: from M pick an
admissible m with probability m^(-beta) / Psi_M(beta), Psi_M(beta) the sum of m^(-beta) over
the admissible m, beta > 1 the
inverse temperature, beta -> infinity recovering the greedy walk. The
demands are unchanged: independence (m coprime to M), dynamics
(lambda(Mm) > lambda(M), lambda the exponent of the unit group) and
transparency (lambda(Mm) = lambda(M), M grows). Which parts of each
fate survive heat, what does each demand grow at finite beta, and
does the answer change over F_2[x], whose ticks sit on a log clock?

THE OBJECT. A state is M >= 1; A(M) is the set of admissible m >= 2
under the demand; Psi_M(beta) = sum of m^(-beta) over A(M). zeta is the
Riemann zeta function; sigma_beta(n) = sum of d^(-beta) over d | n.
W(L) is the wall of growth.py, the largest M with lambda(M) | L. Over
F_2[x] a state is a monic polynomial M, the weight of a monic m is
|m|^(-beta) = 2^(-beta deg m), and c = v_2(lambda(M)).

      coprime to M. Once p | M no later pick touches p: ENTRY-ONCE.

      weight p^(-k beta) u^(-beta) factors and the range of u does not
      depend on k, so P(v_p(m) = k | p | m) = p^(-beta(k-1))

      the same factoring over the primes of one pick makes the depths
      independent. The move m = p is admissible while p does not

      p^(-beta) / (zeta(beta) - 1) at every state: by Levy's
      extension of Borel-Cantelli every prime enters almost surely.
      From seed 1 the limit is prod p^(G_p), G_p independent and
      geometric of ratio p^(-beta), and it is squarefree with

      divides it, coordinate by coordinate.

      divides W(lambda(M))}, the divisors of W/M: finite. So Psi_M(beta)
      = zeta(beta) - sigma_beta(xi), xi = W/M.
  (3) THE OPENING BOUND. m -> pm maps A(M) into itself injectively, so
      the mass of picks divisible by p is at least p^(-beta) Psi_M:
      P(p | pick) >= p^(-beta), with no dependence on the state. By
      Levy's Borel-Cantelli every prime divides infinitely many picks
      almost surely, v_p(M_t) -> infinity at every p, and the limit
      ring lim Z/M_t is Z-hat, at every seed and every beta > 1. The
      greedy walk's lock onto one prime (growth.py) does not survive
      any heat. Exactly: P(p | pick) = p^(-beta) (zeta - sigma(xi/p)) /
      (zeta - sigma(xi)), xi = W/M the headroom, sigma(xi/p) read as 0
      when p does not divide xi.
  (4) THE GENERAL LAW. (3) used only that A(M) is nonempty and
      upward-closed and that the weight is multiplicative, so any
      thermal growth on the divisibility order with those two
      properties reaches Z-hat almost surely.
  (5) THE THREE CLOSURE SHAPES. Independence's A(M) avoids the support
      of M, and that shape alone forces entry-once. Dynamics' A(M) is
      upward-closed and co-finite, and that shape under the thermal
      law at finite beta forces Z-hat; the greedy walk (beta =
      infinity) has the same admissible sets and locks onto one prime

      {2} at every M is downward-closed, finite, never empty, and
      grows 2^infinity. Transparency dies because every move consumes
      a factor of W/M, a budget: from any seed every trajectory, at
      every beta and under every policy, ends at W(lambda(seed))

BETAS = (1.5, 2.0, 3.0)
SPF_N = 400000


def spf_sieve(n):
    spf = list(range(n + 1))
    for i in range(2, int(n ** 0.5) + 1):
        if spf[i] == i:
            for j in range(i * i, n + 1, i):
                if spf[j] == j:
                    spf[j] = i
    return spf


SPF = spf_sieve(SPF_N)


def fac(n):
    """Factorization as a dict, by the sieve below SPF_N, else growth.py."""
    if n > SPF_N:
        return growth.factor(n)
    out = {}
    while n > 1:
        p = SPF[n]
        out[p] = out.get(p, 0) + 1
        n //= p
    return out


def lam_of(f):
    """lambda of a factorization, as an integer."""
    L = 1
    for p, a in f.items():
        if p == 2:
            x = 1 if a == 1 else (2 if a == 2 else 1 << (a - 2))
        else:
            x = (p - 1) * p ** (a - 1)
        L = L // gcd(L, x) * x
    return L


def mul(f, g):
    out = dict(f)
    for p, a in g.items():
        out[p] = out.get(p, 0) + a
    return out


def zeta(beta):
    """Euler-Maclaurin with N = 40 and three Bernoulli terms."""
    N = 40
    s = sum(n ** -beta for n in range(1, N))
    s += N ** (1 - beta) / (beta - 1) + 0.5 * N ** -beta
    b = beta
    s += b / 12 * N ** (-b - 1)
    s -= b * (b + 1) * (b + 2) / 720 * N ** (-b - 3)
    s += b * (b + 1) * (b + 2) * (b + 3) * (b + 4) / 30240 * N ** (-b - 5)
    return s


def divisors(n):
    ds = [1]
    for p, a in fac(n).items():
        ds = [d * p ** i for d in ds for i in range(a + 1)]
    return sorted(ds)


def sigma(n, beta):
    return sum(d ** -beta for d in divisors(n)) if n >= 1 else 0.0


def tail(X, beta):
    """An upper bound for the sum of m^(-beta) over m > X."""
    return X ** (1 - beta) / (beta - 1)


def brute_order_lam(M):
    """The largest element order of (Z/M)^x."""
    best = 1
    for a in range(1, M):
        if gcd(a, M) != 1:
            continue
        x, k = a % M, 1
        while x != 1 % M:
            x = x * a % M
            k += 1
        best = best // gcd(best, k) * k
    return best


class Sampler:
    """Draws m in [lo, hi] with probability proportional to m^(-beta)."""

    def __init__(self, lo, hi, beta):
        self.lo = lo
        acc, cdf = 0.0, []
        for m in range(lo, hi + 1):
            acc += m ** -beta
            cdf.append(acc)
        self.cdf, self.total = cdf, acc

    def draw(self, rng):
        return self.lo + bisect.bisect_left(self.cdf,
                                            rng.random() * self.total)

    e2 = abs(zeta(2.0) - math.pi ** 2 / 6)
    e4 = abs(zeta(4.0) - math.pi ** 4 / 90)
    print(f"  zeta(2) error {e2:.1e}, zeta(4) error {e4:.1e}")
    check("C1 zeta within 1e-12 of pi^2/6 and pi^4/90",
          e2 < 1e-12 and e4 < 1e-12)
    bad = [M for M in range(2, 301) if lam_of(fac(M)) != brute_order_lam(M)]
    check("C2 lambda equals the largest element order, 2 <= M <= 300",
          not bad, str(bad[:5]))
    badf = []
    for M in range(2, 1 << 8):
        L = growth.lam_f2(M)
        units = [a for a in range(1, 1 << growth.pdeg(M))
                 if gcd_f2(a, M) == 1]
        ok = all(f2_powmod(a, L, M) == 1 for a in units)
        for r in fac(L):
            ok = ok and any(f2_powmod(a, L // r, M) != 1 for a in units)
        if not ok:
            badf.append(M)
    check("C2 over F_2[x] lambda is the unit group's exponent at every "
          "monic of degree 1 to 7", not badf, str(badf[:5]))
    rng = random.Random(2)
    s = Sampler(2, 50, 2.0)
    n, cnt = 200000, {}
    for _ in range(n):
        m = s.draw(rng)
        cnt[m] = cnt.get(m, 0) + 1
    worst = 0.0
    for m in range(2, 51):
        pr = m ** -2.0 / s.total
        se = math.sqrt(pr * (1 - pr) / n)
        worst = max(worst, abs(cnt.get(m, 0) / n - pr) / se)
    print(f"  sampler: largest deviation {worst:.2f} standard errors")
    check("C3 the sampler's frequencies within 5 standard errors",
          worst < 5)


def f2_powmod(a, n, M):
    r = 1
    while n:
        if n & 1:
            r = growth.pdivmod(growth.pmul(r, a), M)[1]
        a = growth.pdivmod(growth.pmul(a, a), M)[1]
        n >>= 1
    return r


def gcd_f2(a, b):
    while b:
        a, b = b, growth.pdivmod(a, b)[1]
    return a


# ------------------------------------------------------------ Z: over Z

STATES = (1, 2, 6, 15, 60, 77, 360)
X = 30000


def section_z():
    section("Z  DYNAMICS AND TRANSPARENCY OVER Z")
    FA = [None] + [fac(n) for n in range(1, 2001)]
    viol_c = viol_u = 0
    for M in range(1, 2001):
        LM = lam_of(FA[M])
        xi = growth.wall(LM) // M
        adm = [False] * 201
        for m in range(2, 201):
            a = lam_of(mul(FA[M], FA[m])) != LM
            adm[m] = a
            if a == (xi % m == 0):
                viol_c += 1
        for m in range(2, 201):
            if adm[m]:
                for mm in range(2 * m, 201, m):
                    if not adm[mm]:
                        viol_u += 1
    check("Z1 lambda(Mm) = lambda(M) iff m | W/M, M <= 2000, m <= 200",
          viol_c == 0, f"{viol_c} violations")
    check("Z1 the admissible set is upward-closed in that range",
          viol_u == 0, f"{viol_u} violations")

    zs = {b: zeta(b) for b in BETAS}
    FX = [None] + [fac(n) for n in range(1, X + 1)]
    bad2 = bad3 = low3 = 0
    spec = None
    for M in STATES:
        fM = fac(M)
        LM = lam_of(fM)
        xi = growth.wall(LM) // M
        adm = [m for m in range(2, X + 1)
               if lam_of(mul(fM, FX[m])) != LM]
        for b in BETAS:
            S = sum(m ** -b for m in adm)
            Zf = zs[b] - sigma(xi, b)
            if not (S - 1e-12 <= Zf <= S + tail(X, b)):
                bad2 += 1
            for p in (2, 3, 5, 7, 11, 13):
                Sp = sum(m ** -b for m in adm if m % p == 0)
                tp = p ** -b * tail(X // p, b)
                lo, hi = Sp / (S + tail(X, b)), (Sp + tp) / S
                sDp = sigma(xi // p, b) if xi % p == 0 else 0.0
                Pf = p ** -b * (zs[b] - sDp) / Zf
                if not (lo - 1e-12 <= Pf <= hi + 1e-12):
                    bad3 += 1
                if Pf < p ** -b - 1e-15:
                    low3 += 1
                if (M, b, p) == (6, 2.0, 5):
                    spec = Pf
    print(f"  7 states x 3 betas; P(5 | pick | M = 6, beta = 2) = "
          f"{spec:.7f}")
    check("Z2 Psi_M = zeta - sigma(W/M) inside every brute bracket",
          bad2 == 0, f"{bad2} outside")
    check("Z3 the closed-form opening probability inside every bracket",
          bad3 == 0, f"{bad3} outside")
    check("Z3 every opening probability at or above p^(-beta), and "
          "P(5 | pick | 6, beta 2) = 0.19793", low3 == 0 and
          abs(spec - 0.19793) < 5e-6)

    tomb = {M: growth.wall(lam_of(fac(M))) for M in (24, 240, 504)}
    print(f"  W(lambda(M)) at the tombstones: {tomb}")
    free = all(lam_of(mul(fac(M), fac(m))) != lam_of(fac(M))
               for M in tomb for m in range(2, 1001))
    check("Z4 W(lambda(M)) = M at 24, 240, 504 and every m in 2..1000 "
          "admissible there", all(M == w for M, w in tomb.items()) and free)

    walls = {seed: growth.wall(lam_of(fac(seed))) for seed in (5, 7, 73)}
    print(f"  transparency walls: {walls}")
    check("Z5 the walls W(lambda(seed)) are 240, 504 and 20174525280",
          walls == {5: 240, 7: 504, 73: 20174525280})
    # the lock melts
    def greedy(seed, T):
        f = fac(seed)
        for _ in range(T):
            L = lam_of(f)
            m = 2
            while lam_of(mul(f, fac(m))) == L:
                m += 1
            f = mul(f, fac(m))
        return f

    g = greedy(2, 40)
    print(f"  greedy from 2 after 40 moves: {g}")
    s500 = Sampler(2, 500, 2.0)
    FS = [None] + [fac(n) for n in range(1, 501)]
    rng = random.Random(6)
    opened, hist = 0, {}
    for _ in range(100):
        f = {2: 1}
        first = None
        for t in range(1, 41):
            L = lam_of(f)
            while True:
                m = s500.draw(rng)
                if lam_of(mul(f, FS[m])) != L:
                    break
            f = mul(f, FS[m])
            if first is None and len(f) > 1:
                first = t
        opened += first is not None
        hist[len(f)] = hist.get(len(f), 0) + 1
    print(f"  hot runs opening a second prime by move 40: {opened}/100; "
          f"primes seated at move 40: {dict(sorted(hist.items()))}")
    check("Z6 the greedy walk from 2 stays on the 2-column for 40 moves",
          list(g) == [2])
    check("Z6 at beta = 2 at least 95 of 100 runs open a second prime "
          "by move 40", opened >= 95)

def section_i():
    section("I  THE ZETA MEASURE")
    zs = {b: zeta(b) for b in BETAS}
    worst, bad = 0.0, 0
    for M in (1, 6, 35, 210):
        ps = [p for p in (2, 3, 5, 7, 11, 13) if M % p][:4]
        for b in BETAS:
            for p in ps:
                mass = {}
                base = 0.0
                for m in range(p, X + 1, p):
                    if gcd(m, M) == 1:
                        k = 0
                        n = m
                        while n % p == 0:
                            n //= p
                            k += 1
                        w = m ** -b
                        base += w
                        mass[k] = mass.get(k, 0.0) + w
                tp = p ** -b * tail(X // p, b)
                for k in range(1, 5):
                    law = p ** (-b * (k - 1)) * (1 - p ** -b)
                    lo = mass.get(k, 0.0) / (base + tp)
                    hi = (mass.get(k, 0.0) + tp) / base
                    if not (lo - 1e-12 <= law <= hi + 1e-12):
                        bad += 1
                    worst = max(worst, hi - lo)
    print(f"  widest bracket {worst:.2e}")
    check("I1 P(v_p = k | p | pick) = p^(-beta(k-1))(1 - p^(-beta)) "
          "inside every bracket", bad == 0, f"{bad} outside")

    primes = [p for p in range(2, 200001) if SPF[p] == p]
    for b in BETAS:
        prod = 1.0
        for p in primes:
            prod *= 1 - p ** -b
        rest = sum(n ** -b for n in range(200001, 200050)) + \
            tail(200049, b)
        ok = prod * (1 - rest) - 1e-12 <= 1 / zs[b] <= prod + 1e-12
        print(f"  beta {b}: Euler product {prod:.6f}, 1/zeta "
              f"{1 / zs[b]:.6f}")
        check(f"I2 the crystal probability at beta {b} equals 1/zeta "
              "inside the bracket", ok)
    print(f"  1/zeta(2) = {1 / zs[2.0]:.4f}")

    b = 2.0
    S = sum(m ** -b for m in range(2, X + 1))
    two = sum((1 << k) ** -b for k in range(1, 40))
    P2 = 2 ** -b / (zs[b] - 1)
    Ppow = 1 / ((2 ** b - 1) * (zs[b] - 1))
    lo_ok = (two / (S + tail(X, b)) <= Ppow <= two / S
             and 2 ** -b / (S + tail(X, b)) <= P2 <= 2 ** -b / S)
    print(f"  from seed 1 at beta 2: P(first pick = 2) = {P2:.6f}, "
          f"P(a power of 2) = {Ppow:.6f}; bracket held: {lo_ok}")
    check("I3 the route's first pick: the closed form inside the brute "
          "bracket, 0.38764 and 0.51685 at beta 2",
          lo_ok and abs(P2 - 0.38764) < 5e-6 and abs(Ppow - 0.51685) < 5e-6)

    rng = random.Random(9)
    s = Sampler(2, 10000, 2.0)
    runs, T = 600, 25
    d2 = {}
    d3 = {}
    seated = 0
    for _ in range(runs):
        M = 1
        f = {}
        for _ in range(T):
            while True:
                m = s.draw(rng)
                if gcd(m, M) == 1:
                    break
            M *= m
            for p, a in fac(m).items():
                f[p] = a
        if 2 in f:
            d2[f[2]] = d2.get(f[2], 0) + 1
        if 3 in f:
            d3[f[3]] = d3.get(f[3], 0) + 1
        seated += all(p in f for p in (2, 3, 5))
    p21 = d2.get(1, 0) / sum(d2.values())
    p31 = d3.get(1, 0) / sum(d3.values())
    print(f"  {runs} runs of {T}: P(v_2 = 1) {p21:.3f}, P(v_3 = 1) "
          f"{p31:.3f}, runs seating 2, 3 and 5: {seated}")
    check("I4 Monte Carlo: P(v_2 = 1) in 0.75 +- 0.05 and P(v_3 = 1) in "
          "0.889 +- 0.05", abs(p21 - 0.75) <= 0.05 and abs(p31 - 8 / 9)
          <= 0.05)
    check("I4 every run seats 2, 3 and 5", seated == runs)


# ------------------------------------------------------ F: over F_2[x]

def necklace(d):
    tot = 0
    for e in range(1, d + 1):
        if d % e == 0:
            tot += mobius(e) * 2 ** (d // e)
    return tot // d


def mobius(n):
    f = fac(n)
    if any(a > 1 for a in f.values()):
        return 0
    return -1 if len(f) % 2 else 1


def places(f):
    """A monic's factorization over F_2[x]: {irreducible: depth}."""
    return growth.pfactor(f) if f > 1 else {}


def f2_lam(st):
    L = 1
    for g, a in st.items():
        x = growth.lam_f2_pp(growth.pdeg(g), a)
        L = L // gcd(L, x) * x
    return L


def odd(n):
    while n % 2 == 0:
        n //= 2
    return n


def clog2(a):
    return (a - 1).bit_length()


def clock_of(st):
    L = f2_lam(st)
    return (L & -L).bit_length() - 1, odd(L)


def tests(st, mf, cl=None):
    """The two-test verdict for the move with places mf at state st."""
    c, lodd = cl if cl else clock_of(st)
    clock = any(st.get(g, 0) + a > (1 << c) for g, a in mf.items())
    oddt = any(g not in st and lodd % ((1 << growth.pdeg(g)) - 1)
                for g in mf)
    return clock, oddt


def admissible(st, mf):
    new = dict(st)
    for g, a in mf.items():
        new[g] = new.get(g, 0) + a
    return f2_lam(new) != f2_lam(st)


MONICS = {}


def monics_upto(d):
    if d not in MONICS:
        MONICS[d] = [(m, places(m)) for m in range(2, 1 << (d + 1))]
    return MONICS[d]


def f2_step(st, D, beta, rng):
    """One restricted thermal move by the two tests (F3); None
    at a halt."""
    cl = clock_of(st)
    menu = [(m, mf) for m, mf in monics_upto(D)
            if any(tests(st, mf, cl))]
    if not menu:
        return None
    wts = [2.0 ** (-beta * growth.pdeg(m)) for m, _ in menu]
    m, mf = rng.choices(menu, wts)[0]
    new = dict(st)
    for g, a in mf.items():
        new[g] = new.get(g, 0) + a
    return new


def section_f():
    section("F  OVER F_2[x]")
    cnt = all(necklace(d) == len(growth.IRR[d]) for d in range(1, 11))
    check("F1 the necklace counts equal the sieve at degrees 1 to 10", cnt)
    for b in BETAS:
        # 1 - 2^(-beta d) rounds to 1.0 once beta d > 53, so the factor is
        # taken through log1p: I(d) of them is near exp(-2^(-d)/d).
        prod = math.exp(sum(necklace(d) * math.log1p(-2.0 ** (-b * d))
                            for d in range(1, 41)))
        r = 2 ** (1 - b)
        rest = sum(2.0 ** ((1 - b) * d) for d in range(41, 400))
        ok = prod * (1 - rest) - 1e-12 <= 1 - r <= prod + 1e-12
        print(f"  beta {b}: Euler product {prod:.12f}, 1 - 2^(1-beta) "
              f"{1 - r:.12f}")
        check(f"F1 the crystal probability at beta {b} is 1 - 2^(1-beta)",
              ok)

    bad = 0
    for N in range(2, 1 << 7):
        LN = growth.lam_f2(N)
        for s in range(2, 1 << 7):
            if growth.lam_f2(growth.pmul(N, s)) % LN:
                bad += 1
    check("F2 lambda(N) | lambda(Ns) on every pair of monics of degree "
          "1 to 6", bad == 0, f"{bad} violations")

    rng = random.Random(10)
    battery = [{}, {2: 2}, {2: 5}, {3: 1}, {2: 3, 3: 2}, {7: 1, 2: 1},
               {11: 1, 2: 9}, {2: 17, 7: 1, 13: 1}]
    while len(battery) < 20:
        st, D = {2: 2}, 8
        for _ in range(rng.randrange(2, 9)):
            nxt = f2_step(st, D, 2.0, rng)
            if nxt is None:
                break
            st = nxt
        battery.append(st)
    bad3 = badu = 0
    for st in battery:
        adm = {}
        for m, mf in monics_upto(9):
            a = admissible(st, mf)
            adm[m] = a
            if a != any(tests(st, mf)):
                bad3 += 1
        for m, _ in monics_upto(9):
            if adm[m]:
                for s in range(2, 1 << (10 - growth.pdeg(m))):
                    mm = growth.pmul(m, s)
                    if mm in adm and not adm[mm]:
                        badu += 1
    check("F3 admissible iff the clock or the odd test passes, 20 "
          "states x every monic of degree <= 9", bad3 == 0,
          f"{bad3} violations")
    check("F4 the admissible set is upward-closed there", badu == 0,
          f"{badu} violations")

    bad5 = 0
    for mask in range(1 << 12):
        S = [d for d in range(1, 13) if mask >> (d - 1) & 1]
        L = 1
        for d in S:
            x = (1 << d) - 1
            L = L // gcd(L, x) * x
        for d in range(2, 15):
            if (L % ((1 << d) - 1) == 0) != any(e % d == 0 for e in S):
                bad5 += 1
    check("F5 2^d - 1 | lcm(2^d' - 1 : d' in S) iff d | some d', every "
          "S in {1..12}, d = 2..14", bad5 == 0, f"{bad5} violations")

    rng = random.Random(11)
    halted = runs = led = bud = 0
    table = {}
    for D in (4, 6, 8, 10):
        for b in BETAS:
            for _ in range(50):
                st = {2: 2}
                L0 = f2_lam(st)
                c0 = (L0 & -L0).bit_length() - 1
                deg0 = 2
                T = 0
                while T < 500:
                    nxt = f2_step(st, D, b, rng)
                    if nxt is None:
                        break
                    st = nxt
                    T += 1
                runs += 1
                L = f2_lam(st)
                c = (L & -L).bit_length() - 1
                halted += T < 500
                led += T <= (D - 1) + (c - c0)
                bud += (1 << max(c - 1, 0)) < deg0 + D * T or c == 0
                table.setdefault(D, []).append((T, c))
    for D, rows in table.items():
        Ts = [t for t, _ in rows]
        cs = [c for _, c in rows]
        print(f"  D = {D:2d}: halt move {min(Ts)}..{max(Ts)}, halt clock "
              f"{min(cs)}..{max(cs)}")
    check("F6 every restricted run halts", halted == runs,
          f"{halted}/{runs}")
    check("F6 T <= (D - 1) + (c_T - c_0) and 2^(c_T - 1) < deg M_0 + D T "
          "on every run", led == runs and bud == runs)

    rng = random.Random(12)
    s64 = list(range(2, 65))
    F64 = {m: fac(m) for m in s64}
    alive = two_ok = 0
    for _ in range(50):
        f = {2: 8}

        for _ in range(200):
            L = lam_of(f)
            menu = [m for m in s64 if lam_of(mul(f, F64[m])) != L]
            if 2 not in menu:
                ok2 = False
            if not menu:

            m = rng.choices(menu, [m ** -2.0 for m in menu])[0]

    print(f"  Z, restricted to m <= 64 from 2^8: {alive}/50 alive after 200 "

    rng = random.Random(13)
    opens = 0

        while True:

    print(f"  x + 1 opens in {opens}/100 runs (D = 10, beta 2, from x^2)")

def f2_menu(st, D):
    cl = clock_of(st)
    return [(m, mf) for m, mf in monics_upto(D) if any(tests(st, mf, cl))]


def f2_bill(st, D):
    """The bill formula (12): the cheapest revival as (cost, g, j)."""
    c = clock_of(st)[0]
    best = None
    for d in range(1, D + 1):
        for g in growth.IRR[d]:
            j = (1 << c) + 1 - D // d - st.get(g, 0)
            if best is None or (d * j, d, g) < best[:3]:
                best = (d * j, d, g, j)
    return best[0], best[2], best[3]


def section_b():
    section("B  THE BILL OVER F_2[x]")
    rng = random.Random(14)
    dead = []
    for D in (4, 6, 8, 10):
        for _ in range(10):
            st = {2: 2}
            while True:
                nxt = f2_step(st, D, 2.0, rng)
                if nxt is None:
                    break
                st = nxt
            dead.append((D, st))
    bad_a = brute = 0
    for D, st in dead:
        cost, g, j = f2_bill(st, D)
        revived = dict(st)
        revived[g] = revived.get(g, 0) + j
        bad_a += j < 1 or not f2_menu(revived, D)
        if D > 6 or cost > 10:
            continue
        brute += 1
        for m, mf in monics_upto(cost - 1):
            new = dict(st)
            for h, a in mf.items():
                new[h] = new.get(h, 0) + a
            bad_a += bool(f2_menu(new, D))
    check(f"B1 the bill formula: the least reviving degree, {len(dead)} "
          f"halted states, {brute} against every smaller monic",
          bad_a == 0, f"{bad_a} violations")
    bad_b = late = led0 = 0
    shown = set()
    for D, st in dead:
        st = dict(st)
        bills, led, first = [], False, None
        for k in range(6):
            c = clock_of(st)[0]
            cost, g, j = f2_bill(st, D)
            if led:
                bad_b += not (growth.pdeg(g) == 1 and D < (1 << c))
                bad_b += cost != (1 << (c - 1)) - D
                if len(bills) > first + 1:
                    bad_b += cost != 2 * bills[-1] + D
            bills.append(cost)
            st[g] = st.get(g, 0) + j
            menu = f2_menu(st, D)
            one = growth.pdeg(g) == 1 and D < (1 << c)
            odd0 = clock_of(st)[1]
            m, mf = menu[0]
            for h, a in mf.items():
                st[h] = st.get(h, 0) + a
            if one:
                bad_b += (len(menu) != 1 or mf != {g: D}
                          or clock_of(st) != (c + 1, odd0)
                          or bool(f2_menu(st, D)))
                if first is None:
                    first = k
                led = True
            else:
                while True:
                    nxt = f2_menu(st, D)
                    if not nxt:
                        break
                    for h, a in nxt[0][1].items():
                        st[h] = st.get(h, 0) + a
        late += first is None or first > 1
        led0 += first == 0
        if D not in shown:
            shown.add(D)
            print(f"  D = {D}: bills {bills}, first degree-1 revival at "
                  f"{first}")
        if D == 6 and bills[:5] == [2, 10, 26, 58, 122]:
            shown.add("rec")
    print(f"  runs led by a degree-1 place from their first revival: "
          f"{led0} of {len(dead)}; whose first degree-1 revival came after "
          f"the second: {late}; the bills 2, 10, 26, 58, 122 seen at "
          f"D = 6: {'rec' in shown}")
    check("B2 after a degree-1 revival: degree-1 led, one move g^D, the "
          "clock up by one, the odd part held, halted again, bill "
          "2^(c-1) - D at clock c, bill' = 2 bill + D",
          bad_b == 0, f"{bad_b} violations")


def main():
    t0 = time.time()
    section_c()
    if not all(CHECKS):
        print("\na control failed: no verdict is read")
        raise SystemExit(1)
    section_z()
    section_i()
    section_f()
    section_b()
    print()
    print(f"{sum(CHECKS)}/{len(CHECKS)} checks passed, "
          f"{time.time() - t0:.1f} s")
