audit.py

Checks: RULER: The sign law of a stated interval (property); RULER: The audit world and its two roots (property); RULER: The flip is the sign of one scalar (theorem; observation); RULER: The audit's band counts one sample of three (observation).

Cited on: RULER.

To run it: no other script; needs numpy.

"""audit.py -- one published deletion audit's estimator read root by
root against a target known exactly: where its answer comes from, when
it lands on the wrong side of one half, and what a statement built on
its resamples can and cannot say when the target is not identified.

QUESTION. A mixture-proportion deletion audit (Statistical Membership
Inference, arXiv:2602.01150v2, Proposition 3.1, Lemma 3.2 and
Algorithm 1, read at source) models the audited feature distribution
as F_u = kappa F_out + (1 - kappa) F_in, F_in the member class and F_out the
non-member class, and reports kappa, the FORGETTING RATE. For a scalar
feature, with
    d = mu_out - mu_in,  B = d^2,  A = var_u - var_in,
    G = var_out - var_in + B,
it returns the minimizer of f(p) = (A - pG + p^2 B)^2 over the
candidates {0, 1} and the critical points of f in [0, 1] -- the vertex
v = G/(2B) and the real roots of B p^2 - G p + A. Only the audited
set's VARIANCE is used, never its mean. Its stated uncertainty is the
{5%, 95%} quantiles of the estimate over bootstrap resamples of the
audited set, which the source names a reference range. What does the
estimator's answer depend on, and what do statements built on its
resamples cover?

THE WORLDS.
  DEPTH CELL (a, b). The depth column (forget.py): menu {2, 3} at
  every state, the dated fiber (2^a 3^b, a + b), T = a + b, every
  arrangement of a twos and b threes equally likely. The audited datum
  is the first move; member class = first move 2, non-member = first
  move 3. The FEATURE of a route is the number of 2-moves in the three
  positions after the first. So
      feat_in ~ HG(T - 1, a - 1, 3),  feat_out ~ HG(T - 1, a, 3),
      feat_u ~ HG(T, a, 3)
  (population, successes, draws), and the depth cell, unconditioned, is
  the exact mixture of the two classes at weight kappa = b/T, whose
  distance from 1/2 is the size of the count leak.
  The audit's own modelling assumption holds exactly, and every moment
  is a Fraction. Cells W2 = (12, 3), kappa = 1/5 and W3 = (2, 8), kappa = 4/5.
  GAUSSIAN DIAL (kappa, gamma). F_in = N(0, 1), F_out = N(2, 1 + gamma), the
  audited set a genuine kappa-mixture. d = 2, B = 4, G = gamma + 4.

THE ARGUMENT (written before the engine).
  (A) THE BRIDGE (property). For ANY two-class mixture,
      var_u = kappa var_out + (1 - kappa) var_in + kappa (1 - kappa) d^2,
      so A = kappa G - kappa^2 B identically: p = kappa is a root of the
      population objective in every world, and the roots multiply to
      A/B, so the other is p2 = A/(B kappa). On the dial
      A = kappa gamma + 4 kappa (1 - kappa) and p2 = 1 - kappa + gamma/4:
      EXACT at every gamma. Equal class variances (gamma = 0) give the
      twin {kappa, 1 - kappa}; unequal ones slide the second root, which
      leaves the box at gamma = 4 kappa and, for gamma >= 0, never below
      it. The box, not the data,
      identifies. At the
      depth cells, by hand: W2 A = -1017/63700, G = -45/637,
      B = 9/196, p2 = -113/65; W3 A = 34/225, G = 5/18, B = 1/9,
      p2 = 17/10. Both cells are IDENTIFIED.
  (B) THE LEVEL SET (theorem). Write L(p) = G p - B p^2 for the
      level the objective needs at p; f(p) = (A - L(p))^2, so the
      estimate is the p in [0, 1] whose L(p) is nearest A-hat. If a
      replicate's OWN vertex v lies outside [0, 1] (or B-hat = 0 with
      G-hat != 0), L is strictly monotone on the box and the estimate
      is the monotone continuous map clamp-then-invert of A-hat; so it
      lies above 1/2 exactly when A-hat is past the HALF-BOX LEVEL
          L(1/2) = G/2 - B/4
      on the side where L takes its values for p > 1/2: A-hat < L(1/2)
      when L decreases (v <= 0), A-hat > L(1/2) when it increases
      (v >= 1). The FLIP, the estimate nearer 1 - kappa than kappa, is that
      event or its complement by the side of 1/2 the truth sits on. At
      W2 (v = -0.769, kappa = 1/5) and W3 (v = 1.25, kappa = 4/5) both
      reversals give flip <=> A-hat < L(1/2). With G and B held at the
      population the flip rate is Phi((L(1/2) - A)/sd(A-hat)), sd from
      the exact fourth moments: W2 0.387, 0.283, 0.099 and W3 0.270,
      0.111, 0.003 at n = 50, 200, 1000.
  (C) INSIDE THE BOX (theorem). With B-hat > 0 and v in [0, 1], L
      is concave with maximum L(v), and the returned candidate decides:
      (1) the vertex -- estimate v exactly, above 1/2 iff G-hat > B-hat;
      (2) an endpoint -- 0 or 1 exactly; (3) the one in-box root -- the
      level set on that root's branch: on the falling branch (root >=
      v) above 1/2 iff A-hat < L(1/2) when 1/2 >= v, and always when
      1/2 < v; on the rising branch (root <= v) above 1/2 iff A-hat >
      L(1/2) when 1/2 <= v, and never when 1/2 > v; (4) two in-box
      roots -- both zero f exactly, and the winner is floating-point
      residue and candidate order. On (1) and (2) the side of 1/2 is a
      function of the two CLASS samples alone.
  (D) NO ROOT IN THE BOX (the margin law, observation). A replicate
      has an in-box root exactly when A-hat lies in the range of L over
      [0, 1]; otherwise the tool returns a candidate with no root
      behind it, silently. With G and B at the population the rate is
      the two-tailed normal probability of A-hat leaving that range:
      W2 range [G - B, 0] = [-0.1166, 0], W3 [0, 1/6], margins to the
      near edge 0.0160 and 0.0156; hand rates W2 0.615, 0.413, 0.253
      and W3 0.416, 0.317, 0.144. L(1/2) lies strictly inside the range
      (1/2 is interior to the box), so the flip and the no-root event
      are two cuts of one scalar and meet only beyond the far edge: a
      flip is a ROOT drifting past 1/2, not the fallback.
  (E) THE TANGENCY (property). For a {0, 1} feature with class rates
      mu_in, mu_out and mu_u = kappa mu_out + (1 - kappa) mu_in,
      var_out - var_in = d (1 - mu_out - mu_in), so
      A - B kappa^2 = kappa d (1 - 2 mu_u): the two roots coincide at
      kappa exactly when the audited set is balanced.
      There the range's edge sits ON the population A, the margin is
      zero, and a symmetric normal tail cannot describe the rate; the
      margin law's scope is the non-tangent case.
  (F) THE IDENTIFIED SET (the sign law's instance). Two one-sided
      statements are built from the SAME resamples as the tool's band:
      UPPER, the 95% quantile of the LARGEST in-box root (a resample
      with no in-box root contributing the box top 1), and LOWER, the
      5% quantile of the SMALLEST (no root: 0). The truth is always one
      of the population roots, so reporting the root SET omits a term
      of known sign: widening to the set can only enlarge. At gamma = 0
      the pair should close on [1/5, 4/5], the span of the identified
      set {1/5, 4/5}, and not on a point, the bound on the side of
      the second root refusing to tighten and the other staying honest
      while it tightens; with the root set pushed out of the box
      (gamma = 2, p2 = 1.3) the same
      statement contracts. Per trial UPPER >= LOWER by construction
      (the largest root's 95% quantile is at least the smallest's 5%),
      so the pair is never wrong together: a tautology, printed only as
      the engine's check on itself. The tool's own band, the {5%, 95%}
      quantiles of the argmin, chooses a mode and has no such term.

replicates each (member, non-member and audited samples of size n),
no bootstrap; sample variances with ddof 1. Per replicate: A-hat,
G-hat, B-hat, the estimate, the winning candidate's tag, whether any

def phi(x):
    return 0.5 * (1.0 + erf(x / sqrt(2.0)))


# -------------------------------------------------------------- worlds

def hg_moments(M, K, w=3):
    """Mean, variance, fourth and third central moments of HG(M, K, w)."""
    p = [F(comb(K, c) * comb(M - K, w - c), comb(M, w))
         for c in range(w + 1)]
    mu = sum(c * q for c, q in enumerate(p))
    var = sum((c - mu) ** 2 * q for c, q in enumerate(p))
    m4 = sum((c - mu) ** 4 * q for c, q in enumerate(p))
    m3 = sum((c - mu) ** 3 * q for c, q in enumerate(p))
    return mu, var, m4, m3


class Depth:
    """The depth cell (a, b): exact class moments and the three samplers."""

    def __init__(self, a, b):
        self.a, self.b, self.T = a, b, a + b
        self.name = f"W({a},{b})"
        self.pi = F(b, self.T)
        self.m = hg_moments(self.T - 1, a - 1)
        self.n = hg_moments(self.T - 1, a)
        self.u = hg_moments(self.T, a)
        d = self.n[0] - self.m[0]
        self.B = d * d
        self.A = self.u[1] - self.m[1]
        self.G = self.n[1] - self.m[1] + self.B

    def sd_A(self, n):
        """Exact sd of A-hat = s_u^2 - s_m^2, sample variances ddof 1."""
        def v(mom):
            return float(mom[2]) / n - float(mom[1]) ** 2 * (n - 3) / (
                n * (n - 1))
        return sqrt(v(self.u) + v(self.m))

    def sd_D(self, n):
        """Delta-method sd of D-hat = s_u^2 - s_m^2/2 - s_n^2/2 - dhat^2/4
        from the exact moments: cov(s^2, xbar) = mu3/n within a sample."""
        def v(mom):
            return float(mom[2]) / n - float(mom[1]) ** 2 * (n - 3) / (
                n * (n - 1))
        d = float(self.n[0] - self.m[0])
        vm, vn = float(self.m[1]), float(self.n[1])
        return sqrt(v(self.u) + v(self.m) / 4 + v(self.n) / 4
                    + d * d / 4 * (vm + vn) / n
                    + d / 2 * (float(self.n[3]) - float(self.m[3])) / n)

    def draw(self, rng, n, size=None):
        shape = (n,) if size is None else (size, n)
        T, a = self.T, self.a
        xm = rng.hypergeometric(a - 1, T - a, 3, shape).astype(float)
        xn = rng.hypergeometric(a, T - 1 - a, 3, shape).astype(float)
        xu = rng.hypergeometric(a, T - a, 3, shape).astype(float)
        return xm, xn, xu


class Dial:
    """F_in = N(0, 1), F_out = N(2, 1 + gamma), the audited set a
    kappa-mixture."""

    def __init__(self, pi, gamma):
        self.pi, self.gamma = F(pi), F(gamma)
        self.name = f"DIAL({self.pi},{self.gamma})"
        self.B = F(4)
        self.G = self.gamma + 4
        self.A = self.pi * self.gamma + 4 * self.pi * (1 - self.pi)

    def draw(self, rng, n, size=None):
        shape = (n,) if size is None else (size, n)
        sn = sqrt(1.0 + float(self.gamma))
        xm = rng.normal(0.0, 1.0, shape)
        xn = rng.normal(2.0, sn, shape)
        pick = rng.random(shape) < float(self.pi)
        xu = np.where(pick, rng.normal(2.0, sn, shape),
                      rng.normal(0.0, 1.0, shape))
        return xm, xn, xu


def coefficients(xm, xn, xu):
    """A, G, B from the three samples (last axis), ddof 1."""
    d = xn.mean(-1) - xm.mean(-1)
    B = d * d
    vm = xm.var(-1, ddof=1)
    A = xu.var(-1, ddof=1) - vm
    G = xn.var(-1, ddof=1) - vm + B
    return A, G, B


# ----------------------------------------------------------- estimator

def candidates(A, G, B):
    """The source's candidate set, in its order, nan where absent.

    The critical points of (A - pG + p^2 B)^2 are the roots of
    (B p^2 - G p + A)(2 B p - G), the source's cubic: the vertex and the
    level's two roots, root+ the larger; at B = 0 the one root A/G,
    tagged root+."""
    A, G, B = np.broadcast_arrays(*map(np.asarray, (A, G, B)))
    A, G, B = A.astype(float), G.astype(float), B.astype(float)
    nan = np.full(A.shape, np.nan)
    pos = B > 0
    with np.errstate(divide="ignore", invalid="ignore"):
        v = np.where(pos, G / (2 * B), nan)
        disc = G * G - 4 * A * B
        sq = np.sqrt(np.where(disc >= 0, disc, nan))
        rp = np.where(pos, (G + sq) / (2 * B), nan)
        rm = np.where(pos, (G - sq) / (2 * B), nan)
        lin = (~pos) & (G != 0)
        rp = np.where(lin, A / G, rp)

    def box(x):
        return np.where((x >= 0) & (x <= 1), x, nan)
    return np.stack([np.zeros(A.shape), np.ones(A.shape), box(v),
                     box(rp), box(rm)]), A, G, B


def estimate(A, G, B):
    """Estimate, winning candidate (0 end0, 1 end1, 2 vertex, 3 root+,
    4 root-), the in-box root count, and the candidate stack."""
    C, A, G, B = candidates(A, G, B)
    f = (A - C * G + C * C * B) ** 2
    best = f[0].copy()
    tag = np.zeros(A.shape, dtype=int)
    for k in range(1, 5):
        better = f[k] < best          # an absent candidate is nan: never
        best = np.where(better, f[k], best)
        tag = np.where(better, k, tag)
    est = np.take_along_axis(C, tag[None], 0)[0]
    nroots = (~np.isnan(C[3])).astype(int) + (~np.isnan(C[4])).astype(int)
    return est, tag, nroots, C


def root_span(C):
    """Smallest and largest in-box root per entry, nan where none."""
    R = C[3:5]
    none = np.isnan(R).all(0)
    lo = np.where(none, np.nan, np.where(np.isnan(R), np.inf, R).min(0))
    hi = np.where(none, np.nan, np.where(np.isnan(R), -np.inf, R).max(0))
    return lo, hi

def section_level():
    section("THE LEVEL SET: where the flip comes from")
    law_ok, inbox_ok, branches = True, True, [0, 0]
    rate_ok, frozen_ok, noroot_ok, share_ok = True, True, True, True
    free_total, aside_total, scored_total = 0, 0, 0
    for ci, w in enumerate((W2, W3), start=1):
        pi = float(w.pi)
        A0, G0, B0 = float(w.A), float(w.G), float(w.B)
        h0 = G0 / 2 - B0 / 4
        lo0, hi0 = sorted((0.0, G0 - B0))
        print(f"  {w.name}: kappa = {pi}, L(1/2) = {h0:.7f}, range "
              f"[{lo0:.5f}, {hi0:.5f}], A = {A0:.7f}")
        print("       n   flip  frozen  D-law   noroot  hand  root|flip  "
              "scored aside  cases 1/2/3/4  degenerate")
        for n in NS:
            rng = rng_for(ci, n)
            xm, xn, xu = w.draw(rng, n, R_LEVEL)
            A, G, B = coefficients(xm, xn, xu)
            est, tag, nroots, C = estimate(A, G, B)
            flip = np.abs(est - (1 - pi)) < np.abs(est - pi)
            above = est > 0.5
            h = G / 2 - B / 4
            degen = (B == 0) & (G == 0)
            with np.errstate(divide="ignore", invalid="ignore"):
                v = np.where(B > 0, G / (2 * B), np.nan)
            lin = (B == 0) & (G != 0)
            outside = ((B > 0) & ((v < 0) | (v > 1))) | lin
            falling = ((B > 0) & (v < 0)) | (lin & (G < 0))
            derived = np.where(falling, A < h, A > h)
            law_ok &= bool(np.all(derived[outside] == above[outside]))
            aside = (B > 0) & (v >= 0) & (v <= 1)
            c1 = aside & (tag == 2)
            c2 = aside & ((tag == 0) | (tag == 1))
            c3 = aside & (nroots == 1) & ((tag == 3) | (tag == 4))
            c4 = aside & (nroots == 2) & ((tag == 3) | (tag == 4))
            inbox_ok &= bool(np.all(est[c1] == v[c1]))
            inbox_ok &= bool(np.all(above[c1] == (G[c1] > B[c1])))
            inbox_ok &= bool(np.all((est[c2] == 0) | (est[c2] == 1)))
            d3 = np.where(tag == 3, np.where(0.5 >= v, A < h, True),
                          np.where(0.5 <= v, A > h, False))
            inbox_ok &= bool(np.all(d3[c3] == above[c3]))
            # case (3)'s rows where its inequality decides the side; a
            # root beyond v from 1/2 sits on its side by itself
            branches[0] += int((c3 & (tag == 3) & (v <= 0.5)).sum())
            branches[1] += int((c3 & (tag == 4) & (v >= 0.5)).sum())
            free_total += int(c1.sum() + c2.sum())
            aside_total += int(aside.sum())
            scored_total += int(outside.sum())
            s = w.sd_A(n)
            hand_flip = phi((h0 - A0) / s)
            d_law = phi(-(A0 - h0) / w.sd_D(n))
            hand_nr = phi(-(hi0 - A0) / s) + phi(-(A0 - lo0) / s)
            fr = float(flip.mean())
            noroot = float((nroots == 0).mean())
            share = float(np.isin(tag[flip], (3, 4)).mean()) \
                if flip.any() else float("nan")
            se = sqrt(hand_flip * (1 - hand_flip) / R_LEVEL)
            se_d = sqrt(d_law * (1 - d_law) / R_LEVEL)
            if n > 50:
                frozen_ok &= abs(fr - hand_flip) <= 4 * se
                rate_ok &= abs(fr - d_law) <= 4 * se_d
                noroot_ok &= abs(noroot - hand_nr) <= 0.05
                share_ok &= share >= 0.90
            print(f"    {n:5d}  {fr:.3f} {hand_flip:.3f}   {d_law:.3f}"
                  f"    {noroot:.3f} "
                  f"{hand_nr:.3f}   {share:.3f}     {int(outside.sum()):4d} "
                  f"{int(aside.sum()):4d}   {int(c1.sum())}/{int(c2.sum())}"
                  f"/{int(c3.sum())}/{int(c4.sum())}   {int(degen.sum())}"
                  f"   (se {se_d:.3f})")
            print(f"           sd(D-hat): exact {w.sd_D(n):.4f}, A-hat "
                  f"alone {w.sd_A(n):.4f}, measured "
                  f"{float(np.std(A - h, ddof=1)):.4f}")
    check("P1 the flip is the level set at L(1/2) off the box", law_ok,
          f"{scored_total} scored")
    check("P2 the in-box case split, zero exceptions",
          inbox_ok and min(branches) > 0,
          f"falling {branches[0]}, rising {branches[1]}; side fixed by "
          f"the class samples on {free_total} of {aside_total}")
    print(f"  record: P3 as frozen (G, B at the population, sd of A-hat) "
          f"{'holds' if frozen_ok else 'FAILS'} at n >= 200")
    check("P3 flip rate within 4 se of Phi(-D/sd(D-hat)) at n >= 200",
          rate_ok)
    check("P4 no-root rate within 0.05 of the margin law at n >= 200",
          noroot_ok)
    check("P4 flips are roots, share >= 0.90 at n >= 200", share_ok)


def section_tangency():
    section("THE TANGENCY: a balanced binary feature")
    ok = True
    grid = [F(k, 10) for k in range(1, 10)]
    for qm in grid:
        for qn in grid:
            for pi in grid:
                d = qn - qm
                qu = pi * qn + (1 - pi) * qm
                A = qu * (1 - qu) - qm * (1 - qm)
                ok &= A - d * d * pi * pi == pi * d * (1 - 2 * qu)
    check("P5 A - B kappa^2 = kappa d (1 - 2 mu_u) on the 729-point grid", ok)


def section_band():
    section("THE BAND AND THE IDENTIFIED SET")
    cells = (Dial(F(1, 5), 0), Dial(F(1, 5), 2), Dial(F(4, 5), 0), W2, W3)
    out = {}
    print("  cell             n    FIT cov width   UPPER cov slack   "
          "LOWER cov slack   noroot  both-wrong  FIT3")
    for ci, w in enumerate(cells, start=10):
        pi = float(w.pi)
        for n in NS:
            rng = rng_for(ci, n)
            rows = []
            for _ in range(R_BAND):
                xm, xn, xu = w.draw(rng, n)
                A, G, B = coefficients(xm, xn, xu)
                idx = rng.integers(0, n, (BOOT, n))
                As = xu[idx].var(1, ddof=1) - xm.var(ddof=1)
                est, tag, nroots, C = estimate(As, G, B)
                lo, hi = root_span(C)
                q5, q95 = np.quantile(est, (0.05, 0.95))
                U = float(np.quantile(np.where(np.isnan(hi), 1.0, hi), 0.95))
                L = float(np.quantile(np.where(np.isnan(lo), 0.0, lo), 0.05))
                im = rng.integers(0, n, (BOOT, n))
                i_n = rng.integers(0, n, (BOOT, n))
                est3 = estimate(*coefficients(xm[im], xn[i_n], xu[idx]))[0]
                r5, r95 = np.quantile(est3, (0.05, 0.95))
                rows.append((q5 <= pi <= q95, q95 - q5, pi <= U, U - pi,
                             L <= pi, pi - L, float((nroots == 0).mean()),
                             U < pi and L > pi, r5 <= pi <= r95))
            a = np.array(rows, dtype=float)
            r = dict(fit=a[:, 0].mean(), width=a[:, 1].mean(),
                     up=a[:, 2].mean(), ups=a[:, 3].mean(),
                     lo=a[:, 4].mean(), los=a[:, 5].mean(),
                     nr=a[:, 6].mean(), both=int(a[:, 7].sum()),
                     fit3=a[:, 8].mean())
            out[w.name, n] = r
            print(f"  {w.name:14s} {n:5d}   {r['fit']:.3f} {r['width']:.3f}"
                  f"     {r['up']:.3f} {r['ups']:+.3f}     {r['lo']:.3f} "
                  f"{r['los']:+.3f}    {r['nr']:.3f}   {r['both']}"
                  f"         {r['fit3']:.3f}")
    print("  F the pair is never wrong together, by construction: "
          f"{sum(r['both'] for r in out.values())} trials (record)")

    def sides(name, far, near):
        far_ok = all(out[name, n][far] >= 0.99
                     and out[name, n][far + "s"] >= 0.45 for n in NS)
        near_ok = all(out[name, n][near] >= 0.90 for n in NS) and \
            out[name, 1000][near + "s"] < out[name, 50][near + "s"]
        return far_ok and near_ok
    check("P6 DIAL(1/5,0): UPPER refuses to tighten, LOWER tightens "
          "and covers", sides("DIAL(1/5,0)", "up", "lo"))
    check("P6 DIAL(4/5,0): the roles swap", sides("DIAL(4/5,0)", "lo", "up"))
    check("P7 DIAL(1/5,2): UPPER's slack below 0.10 at n = 1000",
          out["DIAL(1/5,2)", 1000]["ups"] < 0.10,
          f"{out['DIAL(1/5,2)', 1000]['ups']:.3f}")
    check("P8 the tool's band covers <= 0.85 at every depth-cell row",
          all(out[w.name, n]["fit"] <= 0.85 for w in (W2, W3) for n in NS))
    check("P9 FIT3 covers above the tool's band at every depth-cell row "
          "and >= 0.85 at n = 1000",
          all(out[w.name, n]["fit3"] > out[w.name, n]["fit"]
              for w in (W2, W3) for n in NS)
          and all(out[w.name, 1000]["fit3"] >= 0.85 for w in (W2, W3)))
