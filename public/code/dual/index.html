"""
dual.py -- the leading end of base b: what a reader of an integer's
sign, exponent and first t digits computes, and how it mirrors the
trailing end.

QUESTION. Base b writes a positive integer n with e + 1 digits, e =
floor(log_b n). The LEADING numeration reads it top first: its depth-t
TILE is the set of integers with the same digit count and the same t
leading digits, so the archimedean window, size, read to t digits. The
trailing numeration reads the same integer bottom first, and its
depth-t tile is n mod b^t. A map f of the positive integers is READ AT
LOOKAHEAD c when, at every depth t, the depth-t tile of f(n) is a
function of the depth-(t + c) tile of n, over the n with f(n) >= 1
(zero has no leading tile). Which places does each end read and hide,
which operations does the leading end read, at what least lookahead,
and what does it read that no arithmetic map is?

THE ARGUMENT (written before this script).
  (1) THE TILE LEMMA. If e + 1 <= t the depth-t tile of n is {n}.
      Otherwise it is [P b^j, (P + 1) b^j) with j = e + 1 - t, P the
      t-digit prefix: b^j consecutive integers. The tile is DEEP when j
      >= 1. So a deep tile of span j is a complete residue system mod
      b^j, and n mod m (m >= 2) is constant on no tile of length >= 2.
      The predicate [m | n] can still be: a tile shorter than m holding
      no multiple of m decides it false. At base 2, [4, 6) is the depth-2
      tile of 4 and 5 and decides [7 | n].
  (2) THE TWO-ENDS LAW. For m >= 2 and j >= 0: n mod m is a function of
      the last j digits iff m | b^j, and every residue mod m has the
      same count on every span-j leading tile iff m | b^j. The first is
      the suffix read. For the second, a span-j tile is b^j consecutive
      integers: each residue appears b^j/m times when m | b^j, and
      otherwise floor(b^j/m) or floor(b^j/m) + 1 times, both counts
      occurring, on every such tile. So one condition decides both
      ends: depth j at the trailing end reads m exactly where span j
      at the leading end hides it exactly. A prime p is read by some
      trailing depth, and hidden on every deep leading tile, iff p | b.
      A prime not dividing b is read at neither end.
  (3) THE CROWN EXCHANGE. b^(e(x) + e(y)) <= xy < b^(e(x) + e(y) + 2),
      so e(xy) - e(x) - e(y) is 0 or 1: a product's exponent is read
      from the factors' to one bit. A difference's is not. Two points of
      one deep tile of span j differ by any integer in (-b^j, b^j), so
      their difference takes every exponent 0..j - 1, both signs, and
      0. Hence [x = y], the sign of x - y and e(x - y) are functions of
      no pair of depth-t tiles once one is deep: equality and near
      comparison are walled at every depth, while sign and exponent are
      native. A residue ring reads x - y = 0 exactly, channel by
      channel, and on a squarefree modulus the ring's support log
      reaches 0 by a drop to a smaller support. The leading read is a
      chart of the real logarithm that omits 0, and a difference is the
      operation that reaches it. Both logarithms are singular at 0; a
      squarefree residue ring reads through that point, the leading end
      is walled by it, and the trailing end of Z reads x = y only modulo
      b^t.
  (4) THE COSET RIGIDITY. Let a digit set D represent every integer as
      a finite trailing string, as {-a, ..., a} with 2a + 1 >= b and a
      >= 1 does: take d = n mod b in D, n' = (n - d)/b, so |n'| <= (|n|
      + a)/b < |n| while |n| > a/(b - 1), and a/(b - 1) <= a is a
      digit. Then the completions of a trailing prefix of value V and
      length t are exactly V + b^t Z, since the extension's digits
      write any integer z and nothing else. Two such tiles are equal or
      disjoint, so the tiles are the b-adic balls however redundant D
      is, and the trailing Lipschitz and division criteria hold
      unchanged: no digit set buys the trailing end an overlap.
  (5) THE AFFINE CLASS THEOREM. Let f be nondecreasing with |f(n) -
      lambda n| <= C, lambda > 0, and Delta = ceil(C/lambda) + 1. f is
      read at some lookahead iff (SLOPE) lambda = b^r/h for integers r
      >= 0, h >= 1, and (ALIGNMENT) for some K >= 0 every positive
      multiple N of h b^K has f(N) >= lambda N > f(N - 1).
      The crossing of B is n*(B) = min{n : f(n) >= B}, and |n*(B) -
      B/lambda| <= Delta. The depth-t output boundaries are the
      integers M b^J with 1 <= M < b^t; for monotone f a depth-(t + c)
      input tile maps into one depth-t output tile iff no boundary's
      crossing sits strictly inside it, so f is read at lookahead c
      iff every crossing n* with f(n* - 1) >= 1 lying in a deep tile of
      span j = digits(n*) - t - c is its left end, b^j | n*.
      SLOPE. n*(b^J) has at least J - G digits for a constant G, so its
      depth-(1 + c) tile has span at least J - G - 1 - c, and b^(J - G -
      1 - c) divides it. The integer n*(b^J)/b^(J - G - 1 - c) lies within
      Delta b^(G + 1 + c - J) of the fixed real b^(G + 1 + c)/lambda,
      which is therefore an integer: lambda is a power of b over an
      integer, b^r/h once r is taken least.
      ALIGNMENT, necessity. For J >= r, N0 = M b^J / lambda = h M b^(J -
      r) is an integer and the crossing lies within Delta of it, with at
      least t + J - r - 1 digits, so alignment gives b^(J - r - 1 - c) |
      n*. N0 is a multiple of the same power, and once b^(J - r - 1 - c)
      > Delta the two coincide. The threshold J0 depends on neither M
      nor t, so every multiple of h b^(J0 - r) is its own crossing.
      ALIGNMENT, sufficiency. For J >= r + K the crossing of M b^J is N
      = h M b^(J - r), with at most digits(h) + t + J - r digits, so at
      c >= digits(h) its tile has depth at most J - r and N is aligned.
      For J < r + K the crossing is below h b^(t + K - 1) + Delta + 1,
      so it is shallow at c >= digits(h) + K + digits(Delta).
      COROLLARIES. floor((u/v) n) with gcd(u, v) = 1 has lambda = u/v:
      the slope needs rad(u) | rad(b), and then h = v b^r / u, every
      multiple N of h has f(N) = lambda N > f(N - 1), and K = 0. So it is
      read iff rad(u) | rad(b), THE NUMERATOR CRITERION, the denominator
      free. floor((n + s)/v) with 0 < s < v has f(N - 1) = N/v at every
      multiple of v, so it fails at every K: read iff s = 0. n + omega is
      read iff omega = 0. THE SUM CRITERION: f = sum w_i floor(n/v_i),
      w_i >= 1, l = lcm(v_i), U = sum w_i l/v_i, lambda = U/l. f(n) <=
      lambda n with equality iff l | n, and f(N - 1) = lambda N - sum w_i
      when l | N, so the alignment condition holds at K iff l | h b^K iff
      U | b^(r + K): f is read iff rad(U) | rad(b), with U the numerator
      over the lcm, unreduced. At (3, 7), base 10, U = 10 and f is read;
      at (3, 6) U = 3 and lambda = 1/2, so the slope holds and alignment
      fails at every base prime to 3. g = floor(n/3) + floor(n/7) is no
      floor((10n + s)/21), which stays within 1 of 10n/21, since g(20) -
      200/21 = -32/21.
  (6) THE LEAST LOOKAHEAD. With h as in (5), K least, delta =
      digits_b(h), mu = v_b(h) and h' = h/b^mu:
      THE DEEP BOUND. For J >= r + K the crossing of M b^J is N = h M
      b^(J - r), its depth-(t + c) tile has depth digits(hM) + J - r - t
      - c, and N is aligned iff c >= D(M) = digits(hM) - t - v_b(hM). For
      M prime to b, v_b(hM) = mu, so D(M) = delta - mu = digits(h') when
      the product OVERFLOWS into delta + t digits, and delta - mu - 1
      otherwise.
      (v_b is not additive at composite b, 2 * 5 at base 10, which is
      why M is taken prime to b.) The overflow interval [b^(delta + t -
      1)/h, b^t) is nonempty iff h > b^(delta - 1), that is iff h' >=
      2, its length grows with t, and b consecutive integers hold one
      = 1 mod b. So c_min >= c_deep = digits_b(h') - [h' = 1], a deep
      misaligned crossing at c_deep - 1 at every large J; and every
      D(M) <= c_deep.
      THE SHALLOW LAYER. For J < r + K the crossing is below
      b^(delta + t + K - 1) + Delta, so below b^(delta + t + K) when
      Delta <= (b - 1) b^(delta + K), and its tile has depth at most
      delta + K - c. So c_min <= max(c_deep, delta + K) under that
      condition.
      THE LEAST-LOOKAHEAD LAW. When K = 0, b does not divide h, h >= 2
      and Delta <= (b - 1) b^delta: c_min = digits_b(h).
      c_scan, the largest lookahead any crossing the script scans
      needs (PK), is at most c_min. The script counts the cells with
      c_scan <= max(c_deep, delta + K - 1), which is no bound on c_min.
  (7) THE STRUCTURAL SPLIT. A map is read at lookahead 0 iff it sends
      every tile into a tile of the same depth, and nothing there asks
      for arithmetic. At base 2, x(n) = n XOR 2^(e - 1) (e >= 1) flips
      the second digit; at base 10, pi(n) applies the digit permutation
      d -> 9 - d to the second digit; P(n) = b^e is monotone with P(n)/n
      running over (1/b, 1], so no line is within a bounded distance of
      it. All three are read at lookahead 0, and x and pi are not
      monotone. On a finite product of finite fields a map is
      channel-local iff it is a polynomial (the locality criterion), so
      on a squarefree residue ring locality and algebra coincide; the
      trailing end of Z, Z/b^t with t >= 2, is no such ring. At the
      leading end they part.

  (8) THE REDUNDANT READER (written before its engine). Give the
      leading end the digits {-a, ..., a}, 2a + 1 > b, and read a
      string 0.d_1 d_2 ... as y = sum d_i b^-i in [-rho, rho],
      rho = a/(b - 1) > 1/2. (i) The completions of a depth-t
      prefix of value V are exactly the closed interval T = [V - rho
      b^-t, V + rho b^-t]: the j-digit strings write every integer in
      [-a R_j, a R_j], R_j = (b^j - 1)/(b - 1), by induction (the
      intervals [bz - a, bz + a] over consecutive z abut since 2a + 1 >=
      b), and a limit of finite completions is a completion. (ii) T's
      children are [V + d b^-(t+1) - rho b^-(t+1), V + d b^-(t+1) + rho
      b^-(t+1)], d = -a..a; the extreme ones reach V +- (a + rho)
      b^-(t+1) = V +- rho b^-t, so they cover T, and adjacent ones
      overlap by (2 rho - 1) b^-(t+1) > 0. So every subinterval of T of
      length at most (2 rho - 1) b^-(t+1) lies in one child: the
      purchase is a positive Lebesgue number. (iii) Let F map [-rho,
      rho]^k to [-rho, rho], L-Lipschitz in the sup metric. At
      lookahead c with b^c >= 2 rho L / (2 rho - 1), if the depth-t
      output tile holds F of the input's depth-(t + c) tiles, as [-rho,
      rho] does at t = 0, then F of the depth-(t + 1 + c) tiles lies
      inside it with diameter at most 2 rho L b^-(t+1+c) <= (2 rho - 1)
      b^-(t+1), so it fits a child; committing that child keeps the
      hypothesis. So F is read at lookahead max(0, ceil(log_b L +
      log_b(2a/(2a - b + 1)))). At (2, 1) this is max(0,
      ceil(log_2 L) + 1). A scaling y -> (u/v) y with |u/v| <= 1, the
      mean (x + y)/2 and the product xy/rho are Lipschitz, so the
      leading end's walls on them dissolve; the order reads do not.
  (9) THE HEDGE. If moreover a <= b - 1, so rho <= 1, the first nonzero
      digit d_i of a prefix fixes the sign of every completion: |V| -
      rho b^-t >= b^-i (1 - rho) >= 0. So the reader that copies the
      prefix, negated when its first nonzero digit is negative, keeps
      each output tile equal to |T|: y -> |y| is read at lookahead 0.
      Sign is read at no depth: the all-zero prefix's tile holds both
      signs at every depth. At a > b - 1 the first nonzero digit no
      longer fixes the sign: at (2, 2), 0.1 followed by -2's reaches
      1/2 - 2 * 1/2 = -1/2.
  (10) WHAT THE PURCHASE SPENDS. (a) THE ORDER BLUR. Two depth-t tiles
      of values V < V' have completions in both orders iff their
      interiors meet, iff V' - V < 2 rho b^-t; the prefixes are b^-t
      apart at least, so a tile's order is open against the 2K
      neighbours with K = ceil(2a/(b - 1)) - 1, 2K + 1 tiles in all,
      three at (2, 1) and (10, 6), one at a non-redundant end. (b) NO
      NORMALIZATION. The tile of 1 0 ... 0 (t digits) is [1/b - rho
      b^-t, 1/b + rho b^-t], which holds 1/b in its interior at every
      depth, so neither the exponent of y nor its standard string is
      read there.
      (c) THE LEAK. Read an integer with t + j signed digits: a prefix
      of value V has the completions V b^j + z, each z in [-a R_j, a
      R_j] once as a value and N_j(z) times as a string. For p | b,
      R_j = 1 mod p and z = d_0 mod p, where d_0 is the last digit. So
      under counting the residues mod p are uniform on the completions
      iff p | 2a R_j + 1 iff p | 2a + 1, with bias below 1/(2a R_j +
      1), and under the string measure iff p | 2a + 1, with a bias
      independent of j. The non-redundant end hides p exactly (the
      two-ends law); redundancy leaks it unless p | 2a + 1. This
      spends a finite place's hiding, not archimedean data. (d)
      DIVISION'S BIT. y -> x/y is read at no depth on a y-prefix of
      zeros, whose tile holds values of both signs arbitrarily near 0,
      so the quotient's image is unbounded. Given |y| >= D, D x/y is
      (1 + 1/D)-Lipschitz on [-rho, rho] x {D <= |y| <= rho} at rho = 1
      and (8) reads it: the one bit of size the reader cannot make.
  (11) THE PERIOD LAW. Non-redundant digits, multiplier a >= 2, alpha =
      floor(log_b a). An input tile [P b^j, (P + 1) b^j) at depth t' =
      t + l, of span j, maps into a * [P b^j, (P + 1) b^j - 1]; with
      theta = [a P >= b^(t' + alpha)] the image's depth-t output tiles
      have length b^J, J = j + Lam, Lam = l + alpha + theta. The tile is
      an EXCEPTION iff a multiple of b^J lies in (a P b^j, a P b^j + a
      (b^j - 1)], iff 1 <= s <= a (b^j - 1)/b^j with s = (-a P) mod
      b^Lam (s = 0 fails, as b^Lam > a). Over b^Lam consecutive P of one
      class, s runs over the multiples of d = gcd(a, b^Lam), each d
      times, so the count of exceptions is exactly
          d * floor(a (b^j - 1)/(b^j d)),
      a - d when b^j d > a. It is 0 iff d > a (1 - b^-j), and since d |
      a and 1 - b^-j >= 1/2, iff d = a: iff rad(a) | rad(b) and Lam >=
      max_p ceil(v_p(a)/v_p(b)), the numerator criterion's multiplier
      half at its depth threshold. THE COUNTING COLLAPSE: for a prime to
      b on deep tiles (b^j > a) the count is a - 1 per b^Lam, and the
      two classes hold the fractions w0 = (b^(alpha+1) - a)/(a (b - 1))
      and 1 - w0 of the t'-digit P as t' grows, so the density of
      exceptions tends to (a - 1) b^-(l + alpha) (w0 + (1 - w0)/b) =
      (1 - 1/a)/b^l, the base and the multiplier's size gone. THE HUMP:
      weighting each tile by log_b((P + 1)/P), the class fractions are
      1 - xi and xi, xi = {log_b a}, and the density tends to (1 - 1/a)
      H(xi)/b^l, H(xi) = b^(xi-1) (1 + (b - 1)(1 - xi)); ln H is concave and
      0 at xi = 0 and 1, so H > 1 inside.
  (12) THE DUAL HAAR. The mantissas form the compact group R_>0/b^Z,
      whose Haar measure is log-uniform, and the mantissas of the
      depth-t leading tiles with prefix P lie in the arc
      [P, P + 1) b^Z, of Haar log_b((P + 1)/P), Benford's law. The
      arcs have unequal Haar, which is why a density at the leading
      end names its measure; residue classes are cosets of equal Haar,
      which is why none at the trailing end needs to. An arc's Haar is
      invariant under multiplication by every q > 0 because log is a
      homomorphism; counting
      is not.

def ndig(n, b):
    if b == 2:
        return n.bit_length()
    if b == 10:
        return len(str(n)) if n else 0
    d = 0
    while n:
        n //= b
        d += 1
    return d


def vb(n, b):
    k = 0
    while n % b == 0:
        n //= b
        k += 1
    return k


def primes_of(n):
    ps, p = set(), 2
    while p * p <= n:
        while n % p == 0:
            ps.add(p)
            n //= p
        p += 1
    if n > 1:
        ps.add(n)
    return ps


def smooth(u, b):
    return primes_of(u) <= primes_of(b)


def tile_key(n, b, t):
    d = ndig(n, b)
    return d, n // b ** max(0, d - t)


# ---- maps: (f, p, q, C) with lambda = p/q and |f(n) - lambda n| <= C ----

def sum_map(terms):
    l = math.lcm(*[v for _, v in terms])
    U = sum(w * l // v for w, v in terms)
    g = math.gcd(U, l)
    C = (sum(w * (v - 1) * (l // v) for w, v in terms), l)
    return Map(lambda n: sum(w * (n // v) for w, v in terms),
               U // g, l // g, C), U


def frac_map(u, v):
    return Map(lambda n: u * n // v, u, v, (v - 1, v))


def phase_map(s, v):
    return Map(lambda n: (n + s) // v, 1, v, (max(s, v - s), v))


def shift_map(w):
    return Map(lambda n: n + w, 1, 1, (abs(w), 1))


class Map:
    """f nondecreasing, lambda = p/q, |f(n) - lambda n| <= C = Cn/Cd."""

    def __init__(self, f, p, q, C):
        self.f, self.p, self.q = f, p, q
        Cn, Cd = C
        # Delta = ceil(C/lambda) + 1
        self.D = -(-(Cn * q) // (Cd * p)) + 1

    def crossing(self, B):
        f = self.f
        n = max(1, B * self.q // self.p - self.D - 1)
        while n > 1 and f(n - 1) >= B:
            n -= 1
        while f(n) < B:
            n += 1
        return n

    def c_need(self, b, t, M, J):
        """Least c at which the crossing of M b^J is no depth-t witness."""
        n = self.crossing(M * b ** J)
        if n <= 1 or self.f(n - 1) < 1:
            return 0, n
        return max(0, ndig(n, b) - t - vb(n, b)), n

    def scan(self, b, ts, Js):
        best, wit = 0, None
        for t in ts:
            for M in range(1, b ** t):
                if M % b == 0:
                    continue
                for J in Js:
                    c, n = self.c_need(b, t, M, J)
                    if c > best:
                        best, wit = c, (t, M, J, n)
        return best, wit

    def slope(self, b):
        """(r, h) with lambda = b^r / h, r least, or None."""
        r = 0
        while b ** r % self.p:
            r += 1
            if r > 64:
                return None
        return r, self.q * b ** r // self.p

    def alignment_K(self, b, Kmax=8, count=400):
        sp = self.slope(b)
        if sp is None:
            return None
        r, h = sp
        f, p, q = self.f, self.p, self.q
        for K in range(Kmax + 1):
            step = h * b ** K
            if all(f(N) * q >= p * N > f(N - 1) * q
                   for N in range(step, step * (count + 1), step)):
                return K
        return None

def write_digits(n, b, a):
    ds = []
    while not -a <= n <= a:
        d = n % b
        if d > a:
            d -= b
        ds.append(d)
        n = (n - d) // b
    if n:
        ds.append(n)
    return ds

        dl, mu = ndig(h, b), vb(h, b)
        hp = h // b ** mu
        c_deep = ndig(hp, b) - (hp == 1)
        t_ov = 1
        if hp >= 2:
            while not any(math.gcd(M, b) == 1 for M in
                          range(-(-b ** (dl + t_ov - 1) // h), b ** t_ov)):
                t_ov += 1
        ts = range(1, max(3, t_ov) + 1)
        c_scan, wit = m.scan(b, ts, range(0, r + K + 7))
        ok_floor &= c_scan >= c_deep
        if c_deep >= 1:
            found = False
            for t in ts:
                for M in range(1, b ** t):
                    if math.gcd(M, b) != 1:
                        continue
                    c, _ = m.c_need(b, t, M, r + K + 2)
                    found |= c == c_deep
            ok_wit &= found
        D = m.D
        if K == 0 and h % b and h >= 2 and D <= (b - 1) * b ** dl:
            n_law += 1
            ok_law &= c_scan == dl
        if D <= (b - 1) * b ** (dl + K):
            n_up += 1
            ok_up &= c_scan <= max(c_deep, dl + K)
        n_sharp += c_scan <= max(c_deep, dl + K - 1)
        n_meet += c_scan == max(c_deep, dl + K - 1)
        if (b, terms) == (2, [(1, 3), (1, 9)]):
            c3, _ = m.scan(b, range(1, 4), range(0, r + K + 7))
            print(f"     floor(n/3) + floor(n/9), base 2: h = {h}, "
                  f"c_deep = {c_deep}, t_ov = {t_ov}, c_scan = {c_scan}, "
                  f"deciding crossing (t, M, J, n*) = {wit}; to depth 3 "
                  f"c_scan = {c3}")
    print(f"     {len(READ)} read cells; law cells {n_law}; cells under the "
          f"shallow condition {n_up}; c_scan <= max(c_deep, delta + K - 1) "
          f"at {n_sharp}, equal at {n_meet}")
    check("c_scan >= c_deep at every read cell", ok_floor)
    check("a deep crossing needs exactly c_deep at every cell with "
          "c_deep >= 1", ok_wit)
    check("c_scan = digits_b(h), the law's c_min, at every law cell",
          ok_law)
    check("c_scan <= max(c_deep, delta + K) under the shallow condition",
          ok_up)
    print(f"     [{time.time() - t0:.1f} s]")

# ---- the redundant leading end: digits -a..a, 2a + 1 > b, y in [-rho, rho]

import random
from fractions import Fraction as Fr


def rho_of(b, a):
    return Fr(a, b - 1)


def stream_value(ds, b):
    return sum(Fr(d, b ** (k + 1)) for k, d in enumerate(ds))


def tile_of(ds, b, a):
    V, r = stream_value(ds, b), rho_of(b, a) / b ** len(ds)
    return V - r, V + r


def lookahead_for(L, b, a):
    c, need = 0, L * Fr(2 * a, 2 * a - b + 1)
    while b ** c < need:
        c += 1
    return c


def run_reader(F, streams, b, a, c, depth, dom=None):
    """Commit output digits of F at lookahead c; return the depth reached
    (depth when never stuck). F maps a list of input intervals to the
    image interval; dom clips each input interval to the map's domain."""
    rho = rho_of(b, a)
    W = Fr(0)
    for t in range(depth):
        boxes = []
        for i, s in enumerate(streams):
            lo, hi = tile_of(s[:t + 1 + c], b, a)
            if dom:
                lo, hi = max(lo, dom[i][0]), min(hi, dom[i][1])
            boxes.append((lo, hi))
        ilo, ihi = F(boxes)
        step = Fr(1, b ** (t + 1))
        r = rho * step
        d_lo = math.ceil((ihi - W - r) / step)
        d_hi = math.floor((ilo - W + r) / step)
        d_lo, d_hi = max(d_lo, -a), min(d_hi, a)
        if d_lo > d_hi:
            return t
        W += d_lo * step
    return depth


def scale(q):
    def F(boxes):
        lo, hi = boxes[0]
        return min(q * lo, q * hi), max(q * lo, q * hi)
    return F


def mean(boxes):
    (a0, a1), (b0, b1) = boxes
    return (a0 + b0) / 2, (a1 + b1) / 2


def corners(g):
    def F(boxes):
        (a0, a1), (b0, b1) = boxes
        vals = [g(x, y) for x in (a0, a1) for y in (b0, b1)]
        return min(vals), max(vals)
    return F


def section_r():
    print("PR  the redundant reader")

        rho = rho_of(b, a)
        ends = (-a * Fr(1, b) - rho / b, a * Fr(1, b) + rho / b)
        overlap = (Fr(0, 1) + rho / b) - (Fr(1, b) - rho / b)
        ok &= ends == (-rho, rho) and overlap == (2 * rho - 1) / b
    check("R1: j-digit values fill [-a R_j, a R_j]; the children cover "

def section_p(rng):
    print("PP  what the purchase spends")
    ok = True
    for b, a, tmax in ((2, 1, 3), (10, 6, 2), (3, 2, 3)):
        rho = rho_of(b, a)
        K = math.ceil(Fr(2 * a, b - 1)) - 1
        seen = set()
        for t in range(1, tmax + 1):
            R = (b ** t - 1) // (b - 1)
            ks = range(-a * R, a * R + 1)
            r = rho / b ** t

            for k in ks:

                          for k2 in range(k - 3, k + 4))

    bad, cases = [], 0

def exceptional(m, a, b, j, t):
    lo, hi = a * m * b ** j, a * ((m + 1) * b ** j - 1)
    return tile_key(lo, b, t) != tile_key(hi, b, t)


def section_m():
    print("PM  the period law and the measure")
    t0 = time.time()
    bad, zero_bad, scopes = [], [], 0
    plan = {2: ((1, 2, 3), (1, 2, 4)), 6: ((1, 2), (1, 2, 4)),
            10: ((1, 2), (1, 2))}
    for b, (ls, js) in plan.items():
        for a in list(range(2, 13)) + [25]:
            al = ndig(a, b) - 1
            for l in ls:
                for j in js:
                    for th in (0, 1):
                        if th == 1 and b ** al == a:
                            continue
                        Lam = l + al + th
                        P = b ** Lam
                        tp = l + 1
                        while True:
                            cut = -(-b ** (tp + al) // a)
                            lo_c, hi_c = ((b ** (tp - 1), cut) if th == 0
                                          else (cut, b ** tp))
                            if hi_c - lo_c >= P + P // 2 + 2:
                                break
                            tp += 1
                        t = tp - l
                        d = math.gcd(a, P)
                        want = d * ((a * (b ** j - 1)) // (b ** j * d))
                        for start in (lo_c, lo_c + 1, lo_c + P // 2):
                            got = sum(exceptional(m, a, b, j, t)
                                      for m in range(start, start + P))
                            scopes += 1
                            if got != want:
                                bad.append((b, a, l, j, th, start, got,
                                            want))
                        if (want == 0) != (P % a == 0):
                            zero_bad.append((b, a, l, j, th))
    print(f"     {scopes} cases read; off the formula: {bad[:3]}; zero "
          f"locus off a | b^Lam: {zero_bad[:3]}  [{time.time() - t0:.1f} s]")
    check("the exception count over every class is d floor(a (b^j "
          "- 1)/(b^j d))", not bad)
    check("the count is 0 iff a | b^Lam", not zero_bad)

    def H(x, b):
        return b ** (x - 1) * (1 + (b - 1) * (1 - x))

    ok_c = ok_h = True
    for b, a, l, j, tp in ((10, 3, 1, 2, 6), (6, 5, 1, 2, 7),
                           (2, 3, 1, 2, 18), (10, 7, 2, 1, 6)):
        t = tp - l
        ms = range(b ** (tp - 1), b ** tp)
        N = len(ms)
        exc = [m for m in ms if exceptional(m, a, b, j, t)]
        cnt = Fr(len(exc))
        law = Fr(a - 1, a) / b ** l
        ben = sum(math.log((m + 1) / m, b) for m in exc)
        x = math.log(a, b) % 1
        ben_law = (1 - 1 / a) * H(x, b) / b ** l
        print(f"     (b, a, l, j) = ({b}, {a}, {l}, {j}), t' = {tp}: "
              f"counting {float(cnt / N):.6f} vs {float(law):.6f} "
              f"(off by {float(abs(cnt - law * N)):.1f} of {2 * a + 2} "
              f"allowed); log-weighted {ben:.6f} vs {ben_law:.6f}")
        ok_c &= abs(cnt - law * N) <= 2 * a + 2
        ok_h &= abs(ben / ben_law - 1) < 0.02
    check("the counting density is (1 - 1/a)/b^l within (2a + 2)/N", ok_c)
    check("the log-weighted density is (1 - 1/a) H(xi)/b^l within 2%", ok_h)
    hump = all(H(k / 100, b) > 1 for b in (2, 3, 10) for k in range(1, 100))
    check("H > 1 at 99 interior points at bases 2, 3 and 10", hump)
    ok = True
