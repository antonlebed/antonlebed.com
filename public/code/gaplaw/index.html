gaplaw.py

Checks: SETS: On the geometric walk's tail the anchored gap is one product (rule).

Cited on: SETS.

To run it: save gaplaw.py, with flatten.py, sets.py beside it; standard library only.

"""gaplaw.py -- the anchored gap along a geometric walk, in closed form:
where the certificate's size profile stops moving, and what the least
positive value of the anchored box is from there on.

QUESTION. sets.py proves the certificate exact whenever its room D/t*
falls under the ANCHORED GAP g_hat, the least positive sum c_r w_r over
the box c_r in [s_r - k, s_r], s the certificate's sizes. On tilted
cells that gap is tiny and nothing said how tiny. Follow one family of
cells, the WALK W-n: sets.ring at N = 105, M = 15, k = 3, alpha = 3/10,
theta = (n - 1)/n (TILT-3 is W-25). What is g_hat as a function of n,
exactly, and from which n on?

THE OBJECTS. At W-n the atom weights are geometric,
    w_r = theta^r kappa,   kappa = (1 - theta)/(1 - theta^15),
so a box vector c is a POLYNOMIAL P_c(x) = sum c_r x^r of degree < 15
and sum c_r w_r = kappa P_c(theta). Its MOMENTS m_j = sum_r C(r, j) c_r
are its coefficients at x = 1, P_c(x) = sum_j m_j (x - 1)^j, and its
FLATTENING is the least j with m_j != 0 (flatten.py's sense). Since
theta - 1 = -1/n exactly,
    P_c(theta) = sum_j m_j (-1/n)^j.                           (*)
The posteriors are block reads of a fiber of seven: with q = theta^15,
the label owning the fiber block [lo, hi) of atom r has posterior
(q^lo - q^hi)/(1 - q^7). The FAR PROFILE is s = 111112222233333.

THE HAND ATTACK, on paper before the engine.
  (1) THE PROFILE IS DECIDED BY EIGHT SIGNS. Atoms 0..4 carry blocks
      (3, 2, 2), atoms 5..9 (2, 3, 2), atoms 10..14 (2, 2, 3), so the
      pairs read seven posterior values. The far profile keeps 1 - q^3
      at atoms 0..4, 1 - q^2 and q^2 - q^5 at atoms 5..9, and all three
      at atoms 10..14: the level is t = q^2 - q^4, tied at the five
      middle pairs of atoms 10..14 and nowhere else, and the fill takes
      all five. The certificate prints that profile at theta whenever
        O   every value in A exceeds t and every value outside A and
            the tied block is below it (six distinct comparisons);
        C1  cov(A + tied block) >= T;
        C2  cov(A + the tied pairs of atoms 10..13) < T.
      C2 is the fill test: a tied pair covers t times its cost, so a
      tied subset closes the deficit iff A plus it covers T, and the
      costs theta^r kappa fall with r, so the four HEAVIEST tied pairs
      are the best four; when they fail, every proper sub-block fails
      and the fill is all five. C2 also puts cov(A) under T, so no
      value above t is operative, and C1 makes t operative. Every
      condition clears to the sign of an integer polynomial in theta:
      a comparison of block numerators, or
        10 (1 - theta) Phi(X) - 7 (1 - theta^15)(1 - theta^105),
      Phi(X) = sum over the pairs of X of theta^r (q^lo - q^hi).
      A sign constant on [theta_n0, 1) is a proof for every real
      n >= n0: substitute theta = 1 - u, deflate the powers of u,
      scale u = z/n0, and count sign variations under the
      Vincent-Collins-Akritas transform, bisecting (0, 1) until each
      piece reads 0 (no root) or 1 (one root).
  (2) THE ARGMIN IS ONE PRODUCT, AT ONE SHIFT. The box is
      c_r in [-2, 1] at atoms 0..4, [-1, 2] at 5..9, [0, 3] at 10..14.
      V = (x - 1)(x^2 - 1)(x^3 - 1)^2 has coefficients
      1, -1, -1, -1, 2, 2, -1, -1, -1, 1: its 2s need atoms >= 5 and
      its -1s atoms <= 9, so x^a V threads the box at a = 1 only. And
          x V(x) at theta = theta (1 + theta)(1 + theta + theta^2)^2 n^-4
      exactly, since (theta - 1)^4 = n^-4. Its moments: m_4 = 18 and
      m_5 = 63 (expand at theta = 1 - u: 18 (1 - u)(1 - u/2)(1 - 2u)^2
      to first order is 18 - 63 u). So the prediction is
          g_hat = theta (1 + theta)(1 + theta + theta^2)^2
                / ((1 + theta + ... + theta^14) n^4)  ->  (6/5) n^-4,
      a closed form, with no error term left to bound.
  (3) THE PROOF'S SHAPE. Split the nonzero box vectors by flattening
      j. A vector flattened past 4 must be absent from the box (a
      free box of height 3 reaches 6, flatten.py's h(15, 6) = 3, and
      never 7, h(15, 7) = 4; the anchoring must deny 5 and 6). For
      j <= 4, (*) gives
          n^j |P_c(theta)| >= |m_j| - E_j,
          E_j = X_{j+1}/n + sum_{i >= j+2} B_i n^(j-i),
      X_{j+1} the largest |m_{j+1}| over the box's vectors with
      m_0 = ... = m_{j-1} = 0, B_i the largest |m_i| over the whole
      box, which is coordinatewise: max(sum C(r,i) s_r,
      -sum C(r,i)(s_r - 3)). Both fall as n grows, so a margin read at
      n0 holds on the whole tail. Then: j <= 3 has |P| > 18 n^-4 >
      P_V once |m_j| - E_j > 18 n^(j-4); j = 4 with m_4 <= -1 is
      negative once E_4 < 1; m_4 >= 19 exceeds P_V once 19 - E_4 > 18;
      and the least positive m_4 must be 18, whose finitely many
      vectors are each compared with xV exactly, the difference being
      (x - 1)^5 times an integer polynomial whose sign the engine of
      (1) reads on the tail. By coordinates, B_1 = 260 and
      B_2 = 1235, so E_0 < 0.18 and E_1 < 0.86 at n = 1451 without any
      search: only j = 2, 3, 4 need the box's own extremes. A tie
      P_c(theta) = P_V(theta) with c != xV is impossible for n >= 4:

      leading coefficient at most 3 in size.

      every posterior near its block's length over 7, the certificate
      covers 5/7 in the limit against T = 7/10, so D -> 1/70, t* ->
      2/7, and the room D/t* -> 1/20, while g_hat -> 0 as n^-4: on the
      walk's tail the anchored test cannot fire.

# ------------------------------------------------------ polynomials
# Integer lists, low degree first, in theta.

def padd(a, b):
    n = max(len(a), len(b))
    return [(a[i] if i < len(a) else 0) + (b[i] if i < len(b) else 0)
            for i in range(n)]


def pscale(a, s):
    return [x * s for x in a]


def pmul(a, b):
    out = [0] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        if x:
            for j, y in enumerate(b):
                out[i + j] += x * y
    return out


def mono(k, c=1):
    return [0] * k + [c]


def peval(a, x):
    v = 0
    for c in reversed(a):
        v = v * x + c
    return v


def shift1(p):
    """p(z + 1) (a Taylor shift)."""
    p = list(p)
    n = len(p)
    for i in range(n):
        for j in range(n - 2, i - 1, -1):
            p[j] += p[j + 1]
    return p


def variations(p):
    s = [x for x in p if x]
    return sum(1 for a, b in zip(s, s[1:]) if (a > 0) != (b > 0))


def var01(p):
    """Descartes's bound on the number of roots of p in (0, 1)."""
    return variations(shift1(list(reversed(p))))


def tail_poly(G, n0):
    """G at theta = 1 - z/n0, deflated at z = 0, cleared to integers:
    its roots in (0, 1] are the roots of G on [theta_n0, 1)."""
    d = len(G) - 1
    h = [0] * (d + 1)
    for k, g in enumerate(G):
        if g:
            for i in range(k + 1):
                h[i] += g * comb(k, i) * (-1) ** i
    while h and h[-1] == 0:
        h.pop()
    if not h:
        raise ValueError("identically zero")
    m = next(i for i, x in enumerate(h) if x)
    h = h[m:]
    e = len(h) - 1
    return [x * n0 ** (e - i) for i, x in enumerate(h)], m


def isolate(p, lo=F(0), hi=F(1), depth=0):
    """Brackets in z of the roots of p in (lo, hi), p read on (0, 1)."""
    v = var01(p)
    if v == 0:
        return []
    if v == 1:
        return [(lo, hi)]
    if depth > 90:
        raise RuntimeError("isolation did not converge")
    d = len(p) - 1
    left = [x * 2 ** (d - i) for i, x in enumerate(p)]
    right = shift1(left)
    mid = (lo + hi) / 2
    out = isolate(left, lo, mid, depth + 1)
    if right[0] == 0:
        out.append((mid, mid))
    return out + isolate(right, mid, hi, depth + 1)


def tail_sign(G, n0=N0):
    """(sign, roots as z-brackets, multiplicity at theta = 1, the
    cleared polynomial). A sign is returned only when no root lies in
    (0, 1] and both ends agree: a proof that G keeps that sign at
    theta = (n - 1)/n for every real n >= n0."""
    p, m = tail_poly(G, n0)
    roots = isolate(p)
    end = peval(p, 1)
    s0 = (p[0] > 0) - (p[0] < 0)
    s1 = (end > 0) - (end < 0)
    sign = s0 if (not roots and s0 == s1) else None
    return sign, roots, m, p


def refine(p, n0, a, b, steps=40):
    """Narrow a one-root z-bracket (a, b) by bisection; returned as n."""
    fa = peval(p, a)
    for _ in range(steps):
        c = (a + b) / 2
        fc = peval(p, c)
        if (fc > 0) == (fa > 0):
            a, fa = c, fc
        else:
            b = c
    return float(F(n0) / b), float(F(n0) / a) if a else float("inf")


# ------------------------------------------------------- the walk

def blocks():
    """Per atom, per label, the fiber block (lo, hi) the label owns."""
    out = []
    for r in range(M):
        ys = [K * (r + j * M) // NR for j in range(C)]
        row = []
        for y in range(K):
            js = [j for j in range(C) if ys[j] == y]
            row.append((js[0], js[-1] + 1))
        out.append(row)
    return out


def num(lo, hi):
    """q^lo - q^hi as a polynomial in theta."""
    return padd(mono(M * lo), mono(M * hi, -1))


def phi(pairs):
    tot = [0]
    for r, lo, hi in pairs:
        tot = padd(tot, pmul(mono(r), num(lo, hi)))
    return tot


def coverage_test(pairs):
    """Positive iff cov(pairs) > T = 7/10, kappa/(1 - q^7) cleared."""
    lhs = pscale(pmul([1, -1], phi(pairs)), 10)
    rhs = pscale(pmul(padd([1], mono(M, -1)), padd([1], mono(NR, -1))), -7)
    return padd(lhs, rhs)


def theta(n):
    return F(n - 1, n)


def far_structure():
    """A, the tied block and the eight tests of the hand attack (1)."""
    bl = blocks()
    th = theta(N0)
    lvl = (2, 4)
    tied = [(r, *bl[r][y]) for r in range(M) for y in range(K)
            if bl[r][y] == lvl]
    A = []
    for r in range(M):
        vals = sorted(((peval(num(*b), th), b) for b in bl[r]),
                      reverse=True)
        A += [(r, *b) for _, b in vals[:FAR[r]] if b != lvl]
    t = num(*lvl)
    inside = {(lo, hi) for _, lo, hi in A}
    outside = {b for row in bl for b in row} - inside - {lvl}
    tests = []
    for b in sorted(inside):
        tests.append((f"O  q^{b[0]} - q^{b[1]} above the level",
                      padd(num(*b), pscale(t, -1)), 1))
    for b in sorted(outside):
        tests.append((f"O  q^{b[0]} - q^{b[1]} below the level",
                      padd(num(*b), pscale(t, -1)), -1))
    tests.append(("C1 cov(A + tied block) >= T",
                  coverage_test(A + tied), 1))
    heavy = [x for x in tied if x[0] <= 13]
    tests.append(("C2 cov(A + tied pairs of atoms 10..13) < T",
                  coverage_test(A + heavy), -1))
    return A, tied, tests


# -------------------------------------------------------- the box

def half(lows, highs, atoms, top=7):
    """Every sub-vector over `atoms` with its partial moments."""
    out = []
    for vals in product(*[range(lows[r], highs[r] + 1) for r in atoms]):
        m = tuple(sum(comb(r, j) * x for r, x in zip(atoms, vals))
                  for j in range(top))
        out.append((m, vals))
    return out


def group(side, j):
    g = {}
    for m, v in side:
        g.setdefault(m[:j], []).append((m, v))
    return g


def extreme_next(L, R, j, i):
    """max |m_i| over box vectors with m_0 = ... = m_{j-1} = 0."""
    gl, gr = group(L, j), group(R, j)
    best = 0
    for key, ls in gl.items():
        rs = gr.get(tuple(-x for x in key))
        if not rs:
            continue
        lmax, lmin = max(m[i] for m, _ in ls), min(m[i] for m, _ in ls)
        rmax, rmin = max(m[i] for m, _ in rs), min(m[i] for m, _ in rs)
        best = max(best, lmax + rmax, -(lmin + rmin))
    return best


def flattened(L, R, j):
    """Every box vector with m_0 = ... = m_{j-1} = 0, as (m, vector)."""
    gl, gr = group(L, j), group(R, j)
    out = []
    for key, ls in gl.items():
        for mr, vr in gr.get(tuple(-x for x in key), ()):
            for ml, vl in ls:
                out.append((tuple(a + b for a, b in zip(ml, mr)), vl + vr))
    return out


def m4_census(L, R):
    """The least positive m_4 over vectors with m_0..m_3 = 0, and every
    vector attaining it."""
    gl, gr = group(L, 4), group(R, 4)
    least = None
    for key, ls in gl.items():
        rs = gr.get(tuple(-x for x in key))
        if not rs:
            continue
        r4 = sorted(m[4] for m, _ in rs)
        for m, _ in ls:
            k = bisect_right(r4, -m[4])
            if k < len(r4):
                v = m[4] + r4[k]
                if least is None or v < least:
                    least = v
    hits = []
    for key, ls in gl.items():
        for mr, vr in gr.get(tuple(-x for x in key), ()):
            for ml, vl in ls:
                if ml[4] + mr[4] == least:
                    hits.append(vl + vr)
    return least, hits


def box_bounds(s):
    """B_i, the largest |m_i| over the box, read coordinatewise."""
    return [max(sum(comb(r, i) * s[r] for r in range(len(s))),
                -sum(comb(r, i) * (s[r] - K) for r in range(len(s))))
            for i in range(len(s))]


V = pmul(pmul([-1, 1], [-1, 0, 1]), pmul([-1, 0, 0, 1], [-1, 0, 0, 1]))
XV = pmul(mono(1), V)


def closed_form(n):
    """kappa xV(theta): the predicted anchored gap in cost units."""
    th = theta(n)
    kappa = (1 - th) / (1 - th ** M)
    return kappa * peval(XV, th)

def argmin_sizes(an):
    """OPT with one optimal size vector: the two halves' (coverage,
    cost) lists joined through a suffix minimum on the right."""
    sc = an.sc

    def side(atoms):
        return [(sum(sc.V[r][x] for r, x in zip(atoms, s)),
                 sum(sc.W[r] * x for r, x in zip(atoms, s)), s)
                for s in product(range(K + 1), repeat=len(atoms))]
    L, R = side(range(8)), sorted(side(range(8, M)))
    best = [None] * (len(R) + 1)
    for i in range(len(R) - 1, -1, -1):
        b = best[i + 1]
        best[i] = i if b is None or R[i][1] < R[b][1] else b
    vs = [v for v, _, _ in R]
    out = None
    for v, c, s in L:
        j = bisect_left(vs, sc.TQ - v)
        if j < len(R):
            k = best[j]
            if out is None or c + R[k][1] < out[0]:
                out = (c + R[k][1], s + R[k][2])
    return out

        gain = F(an.cert - opt, an.sc.Q)

              f"(CERT - OPT) n = {float(gain * n):.7f}  moments of "

OPT_TAIL = (0,) + (1,) * 6 + (3,) * 8


def cells():
    """Every (atom, block) as (x, length, (r, lo, hi)), x its first point."""
    return [(r + M * lo, hi - lo, (r, lo, hi))
            for r, row in enumerate(blocks()) for lo, hi in row]


def cell_num(r, lo, hi):
    return pmul(mono(r), num(lo, hi))


def moment_table(atoms=M):
    """(S, h) -> {first moment: count} over every size vector, by atoms."""
    tab = {(0, 0): {0: 1}}
    for r in range(atoms):
        nxt = {}
        for (S, h), mom in tab.items():
            for x in range(K + 1):
                key = (S + x, h + (x > 0))
                d = nxt.setdefault(key, {})
                for m, c in mom.items():
                    d[m + r * x] = d.get(m + r * x, 0) + c
        tab = nxt
    return tab


def best_moment(served):
    """Largest sum r s_r over s_r in 1..3 on the served atoms, sum 30:
    the extra slots go two at a time to the heaviest-index atoms."""
    extra, tot = 30 - len(served), sum(served)
    for r in sorted(served, reverse=True):
        x = min(2, extra)
        tot += r * x
        extra -= x
    return tot if extra == 0 else -1


def section_tail_proof():
    section("THE TAIL'S OPTIMUM, PROVED (the second slate)")
    cs = cells()
    heavy = sorted(c for c in cs if c[1] == 3)
    light = sorted(c for c in cs if c[1] == 2)
    th = theta(N0)
    mass = {c: peval(cell_num(*c[2]), th) for c in cs}
    top = sorted(cs, key=lambda c: -mass[c])
    s2 = heavy + light[:14]
    ok = set(top[:29]) == set(s2) and set(top[:15]) == set(heavy)
    check("KB at n = 1451 the exact cell order puts the 15 heavy cells "
          "on top and the 14 least-x light cells next", ok)
    rows = blocks()
    opt = []
    for r, sz in enumerate(OPT_TAIL):
        order = sorted(rows[r], key=lambda b: (-(b[1] - b[0]), b[0]))
        opt += [(r, lo, hi) for lo, hi in order[:sz]]
    hx, lx = heavy[-1], light[0]
    tests = [
        (f"S0 heavy cell x = {hx[0]} outweighs light cell x = {lx[0]}",
         padd(cell_num(*hx[2]), pscale(cell_num(*lx[2]), -1)), 1),
        ("S1 the optimum's cells cover T", coverage_test(opt), 1),
        ("S2 15 heavy + 14 least-x light cells cover < T",
         coverage_test([c[2] for c in s2]), -1),
        ("S3b 12 least-x heavy + 18 least-x light cells cover < T",
         coverage_test([c[2] for c in heavy[:12] + light[:18]]), -1),
    ]
    for name, G, want in tests:
        sign, roots, m, _ = tail_sign(G)
        print(f"  {name}: degree {len(G) - 1}, multiplicity {m} at 1, "
              f"sign {sign}, roots on the tail {len(roots)}")
        check(name, sign == want and not roots)
    bad, worst, owed = [], None, 0
    for gone in [(a, b) for a in range(M) for b in range(a + 1, M)]:
        served = [r for r in range(M) if r not in gone]
        if best_moment(served) < 273:
            continue
        owed += 1
        sv = [c for c in light if c[2][0] not in gone][:17]
        G = coverage_test([c[2] for c in heavy if c[2][0] not in gone]
                          + [c[2] for c in sv])
        sign, roots, _, _ = tail_sign(G)
        if sign != -1 or roots:
            bad.append(gone)
        v = peval(G, th)
        if worst is None or v > worst[0]:
            worst = (v, gone)
    print(f"  S3a: {owed} of 105 served sets of 13 atoms admit a 30-slot "
          f"moment >= 273; {len(bad)} failing"
          + (f" {bad}" if bad else "") + f"; nearest to T at n = 1451 "
          f"abandons atoms {worst[1]}")
    gone = (13, 14)
    sv = [c for c in light if c[2][0] not in gone][:17]
    sign, roots, _, _ = tail_sign(coverage_test(
        [c[2] for c in heavy if c[2][0] not in gone] + [c[2] for c in sv]))
    m1314 = best_moment([r for r in range(M) if r not in gone])
    verdict = (f"has {len(roots)} root(s) on the tail" if roots
               else f"reads sign {sign}")
    print(f"  the served set abandoning atoms 13 and 14: the bound "
          f"{verdict}, and its best 30-slot moment is {m1314}")
    check("S3a every 30-slot rule serving 13 atoms at first moment >= 273 "
          "covers < T", not bad and m1314 == 218)

    tab = moment_table()
    brute = {}
    for v in product(range(K + 1), repeat=6):
        key = (sum(v), sum(1 for x in v if x))
        m = sum(r * x for r, x in enumerate(v))
        brute.setdefault(key, {})
        brute[key][m] = brute[key].get(m, 0) + 1
    check("KB the moment table equals brute force on six atoms",
          moment_table(6) == brute)
    pool = {}
    for h in (14, 15):
        for m, c in tab.get((30, h), {}).items():
            pool[m] = pool.get(m, 0) + c
        best = max(tab[(30, h)])

              f"({tab[(30, h)][best]} vector(s))")
    ms = sorted(pool, reverse=True)
    mo = sum(r * x for r, x in enumerate(OPT_TAIL))
    print(f"  pooled: largest {ms[0]} ({pool[ms[0]]} vector(s)), next "
          f"{ms[1]} ({pool[ms[1]]}); 011111133333333 reads {mo}")
    check("the first moment's maximum is unique and is 011111133333333",
