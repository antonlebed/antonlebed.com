Ring Substrate

Can ring arithmetic serve as the SOLE computation substrate? Not CRT decomposing a neural network. Not CRT as a technique. The ring IS the latent space. Every intermediate value is a ring element. Every operation is ring arithmetic. Zero floats.

This page reports the first Ring Substrate experiment: context-dependent function learning with 4 ring multiplications, evolutionary per-channel search, and ring vs random coprime control.

Architecture

All computation is ring arithmetic. No floats, no dot-product attention, no dense FFN. The ring's structure IS the machine.

ATTEND
Channel matching
coupling(context, prototype) = count of channels where ctx%q == proto%q. Replaces dot-product attention.
TRANSFORM
Ring multiplication
output_ch = (input_ch * weight_ch) % q_ch. Per-channel independence = block-diagonal for free.
SELECT
Argmax
Pick prototype with highest channel match. Route to corresponding weight.
LEARN
Per-channel evolution
Mutate one channel of one parameter. Accept if ch_score improves. 200 generations x 56 trials.

Basin Geometry

Is the ring multiplicative structure a genuine attractor, or a brittle single point? A 2D-LUT automaton with 3750 parameters can compute EXACT ring multiplication (product of tokens mod N via per-channel products mod q). With correct initialization, all 7 channels achieve 100% accuracy. But can coordinate descent (CD) FIND this solution?

Basin Geometry Theorem (PROVED)
The multiplicative basin has measurable width that scales inversely with channel modulus. Perturbing 10% of entries from the exact solution: CD recovers to 96% (3360/3500). Small channels (q<=17) recover to 100%. Z/25 recovers to 96%. Z/49 (the depth channel) recovers to only 76% -- the basin narrows with complexity. Seeding 90% of entries correctly from outside the basin: CD converges to 95%. Seeding 50%: only 45%. Critical threshold: between 50-90% correct entries.
NOT point-like
10% perturbation -> 96% recovery
The multiplicative solution is a genuine attractor with measurable width. Near-correct initializations converge.
Channel-dependent
Z/49=76%, Z/8=100%
Basin width scales inversely with modulus q. Larger state spaces have narrower basins. The depth prime (b=7, channel Z/49) is always the bottleneck.
Contradiction effect
50% correct = only 13% accuracy
Half-multiplicative half-additive entries score 455/3500 (13%) pre-CD. Correctness doesn't compose linearly -- a 5-step sequence needs ALL entries correct. Mixed tables create contradictory transitions that destroy path coherence.
Modular discontinuity
97% entries differ
Additive (h+x)%q and multiplicative (h*x)%q agree at only 110/3750 entries (3%). Smooth operator morphing changes >90% per step regardless of step count. Combined with 10% basin tolerance: curriculum learning is structurally IMPOSSIBLE in modular arithmetic.
Attractor thesis
Selection, not gradient
The basin has width (perturbation-stable) but smooth paths don't exist (modular discontinuity). Ring multiplication is reachable only through structural encoding or population selection -- exactly how biology works. The axiom structure IS the structural prior.
CD depth saturation
Pass 3 ceiling for all conditions
Allowing up to 20 CD passes (instead of 2): ALL conditions stop at pass 3 with no further improvement. The 76% ceiling for Z/49 is STRUCTURAL, not search-limited. Basin width gradient: 5% perturbation gives 88% recovery, 10% gives 77%, 20% gives 45%. Z/49 alone from additive start: only 2% recovery (vs 95% for Z/25). Reynolds number analogy: Z/49 is in the turbulent regime where more iterations cannot converge.

What We Know

Ring arithmetic is a viable computation substrate. Per-channel automata learn real structure via coordinate descent on integer modular operations. Zero floats. Zero gradients. The paradigm works.

The architecture story has a clear arc. Additive models (LUT, GLUT, PLUT) hit an 88-89% overfit ceiling on +1 accumulation. Nonlinear 2D-LUT breaks through, scaling cleanly (91% to 97% overfit at N=1000/5000). Per-step partitioned 2D-PLUT compounds: +21pp over 2D-LUT on +1 task, +28pp on pattern extraction (81.4% vs 53.2%). The 2D-PLUT is architecturally universal -- correct init achieves 100% on BOTH memory tasks (copy, THM 271/277) and computation tasks (pattern, THM 276). But it is NOT universally trainable from default init: on copy, 2D-PLUT default = 99/1400 (chance), matching the 2D-LUT additive barrier. The coordination barrier (THM 277) persists: positions 1-4 must ALL learn preserve-h simultaneously, and no single-entry CD change helps because remaining positions corrupt state. PLUT avoids this because its default (all zeros) means positions 1-4 already contribute nothing -- correct for copy. CD only fixes position 0. The implication: 2D-PLUT + task-appropriate init = universal. The initialization IS the inductive bias.

The multiplicative basin is a genuine attractor: perturbation-stable but unreachable by smooth optimization (modular discontinuity). Evolution preserves but cannot discover. Crossover helps marginally. The structure requires a structural prior -- exactly how biology works. The axiom IS the structural prior.

Three emergent patterns bridge to transformer architecture: the 490 split (ALIVE channels route, DEAD channels carry data), the attention sink (position 0 dominates), and capacity partitioning (independent per-step tables = CRT independence at a higher level). All discovered, not designed. Same information-routing attractor at 18750 params vs billions. A fourth pattern -- 490-gated bloom (selective decoupling of perception vs strategy channels) -- was designed from the 490 split and confirmed: DEAD preservation protects learned structure during bloom-aware training.

The 490 gating story has two chapters. At low per-channel capacity (2D-LUT, ~7.5 params/sample), 490 bloom-aware training helps: DEAD channels learn informant roles through cross-channel scoring, gaining +5.1% on working memory tasks. At high capacity (2D-PLUT, ~37.5 params/sample), the benefit REVERSES: per-channel PLUT (333) exceeds 490-aware PLUT (261) by +28%. The crossover mechanism: per-position tables give ALIVE channels position-specific patterns that bloom (a position-independent perturbation) destroys. DEAD channels are invariant in all conditions. The implication: maximize per-channel capacity first; cross-channel coordination is a low-capacity compensation, not a universal benefit.

Depth is the current frontier. Stacking two 2D-LUT layers (L1 -> 490-bloom -> L2 re-processing the same sequence) degrades accuracy: -34 (-13.4%) at 2-back. Root cause: per-channel CD tables are fragile to varied initial states. The single-layer 2D-PLUT per-channel remains the best CRT-LM architecture. The capacity-gating crossover implies: the next advance is in per-channel model richness (beyond lookup tables), not in cross-channel coordination.

MEDIAL AXIS CONVERGENCE: applying the 7 CRT spatial transforms (identity, 180deg, color-invert, vflip, hflip, 90deg, transpose) to 2D grid cells reveals a spatial structure in channel independence. Medial axis diversity is always less than or equal to edge diversity (9/15 shapes strict inequality, 6/15 equality). Two mechanisms: (1) aperiodic color content makes different transforms see different values (tested on gradients), (2) non-transform-symmetric shapes cause edge transforms to map cells to background (tested on bars, T-shape, diamond, circle). Equality holds only when BOTH shape and color are transform-symmetric (centered rectangles with uniform/periodic content). Tested across 15 shapes including non-rectangular -- the effect persists for horizontal, vertical, mixed, single-point, and rotationally symmetric medial axes. The skeleton is the CRT convergence point where all 7 channels agree. The boundary is where channels carry independent information.

STOCHASTIC SIGNAL-NOISE SEPARATION: the first non-deterministic CRT-LM experiment. Stochastic +1 task: target is (last+1)%N with probability (1-p), random with probability p. At all noise levels (p=10%, 30%, 50%), 2D-LUT CRT channels separate signal from noise. At N=500: signal degrades gracefully (580->542->447->408 permil), noise stays at chance (58-72 permil), ratio 5.7x-9.3x. At N=1000: separation nearly DOUBLES -- signal improves (709->719->600->487 permil), noise stays at chance (40-60 permil), ratio 8.4x-18.0x. Signal/noise ratio scales with data: CRT channels learn more signal without learning more noise. At p=10% with N=1000, signal permil (719) slightly exceeded p=0 (709) at the original seed (+10 permil), but multi-seed verification (5 seeds) FALSIFIED this as noise regularization: 4/5 seeds show noise hurts (mean delta = -15 permil). The +10 permil was within cross-seed variance (41 permil range). b-channel (Z/49) maintains perfect test noise rejection at both scales (0 hits). CRT channel independence provides SCALING noise immunity -- the more data, the better the separation.

POSITION AMBIGUITY: alternating add/mul task tests position-free 2D-LUT on heterogeneous operations. Even positions add, odd positions multiply -- per-channel decomposable, but same (h,x) pairs require different operations at different positions. At N=500, seq_len=5: pure addition 100%, pure multiplication 27.3% test, alternating 9.9% test. DESTRUCTIVE INTERFERENCE: alternating is WORSE than pure multiplication. CD optimizes each LUT entry for the majority operation at that (h,x) pair, but the choice DAMAGES the minority usage. All channels collapse: Z/8 drops from 82.5% (pure mul) to 18% (alt). Initialization irrelevant (additive vs multiplicative init converge to same CD result). IMPLICATION: position-free architectures are limited to homogeneous-operation tasks. Heterogeneous tasks require position-aware models (PLUT/2D-PLUT).

POSITION-AWARENESS DISSOLUTION: 2D-PLUT (per-position 2D-LUT) partially dissolves position ambiguity. Correct initialization (additive at even, multiplicative at odd positions) achieves 100% -- the architecture is fully expressive. From additive default, CD achieves 76.3% train / 15.8% test (2D-PLUT) vs 48.0% / 9.9% (2D-LUT), a 59% improvement ratio on both metrics. Per-channel: Z/8 gains +119% (36->79), Z/9 +57% (37->58), while Z/49 is unchanged (4). The mechanism: position separation lets even-position tables retain their correct additive default while odd-position tables face the multiplicative basin wall independently -- no destructive interference. But basin crossing at odd positions remains the capacity-gated bottleneck: small q crosses, large q stays stuck. The overfit ratio is identical (12.1x for both architectures), meaning position-awareness shifts accuracy without changing capacity dynamics.

PARITY DETECTION: value-conditional task (add if input even, multiply if odd) reveals a new structural role for D. The D-channel (q=8, the SOLE even modulus) achieves 96% from CD, 100% with correct init. Root cause: x mod q preserves parity iff q is even (since kq is even for even q). All odd channels (q=9,25,49,11,13,17) are parity-blind: both even and odd inputs map uniformly to every residue class. Aggregate 21.9% beats alternating 9.9% by 2.2x because D faces zero interference on conditional tasks (each x%8 entry has a unique correct target). STRUCTURAL IMPLICATION: parity-conditional tasks require cross-channel information sharing -- odd channels need D-channel parity signal. This is a concrete instance of the DEAD-informs-ALIVE principle: D (a DEAD perception channel) carries information that ALIVE strategy channels structurally cannot access. The bridge prime IS the parity bridge.

DIVISIBILITY SPECTRUM: per-prime divisibility conditioning (add if x%p==0, else multiply) across all 7 primes reveals two detection regimes. THIN CHANNELS (L=11, GATE=13, ESCAPE=17, all depth 1): 100% accuracy on own-prime divisibility. The condition maps to a single residue (x%q==0), giving a clean 1-vs-rest LUT partition. CD trivially learns the rule. FAT DATA CHANNELS (K=9, E=25, b=49, all depth 2): NOT best on their own-prime conditions despite having the information (p|q). Accuracy ordering: D>K>L>GATE>ESCAPE>E>b (monotonically with 1/q). The thin-vs-fat split partially maps to the 490 boundary: thin ALIVE channels {L,GATE,ESCAPE} are perfect condition detectors. Fat DEAD channels {D,E,b} provide resolution but need more data. K(Z/9) is the boundary case -- ALIVE but fat, D-dominated at N=500. The axiom's Pareto exponents create this hierarchy structurally.

FAT CHANNEL CAPACITY CROSSOVER: D's dominance on fat-prime conditions (above) is a FINITE-SAMPLE ARTIFACT. Scaling from N=500 to N=25000 reveals the full crossover. K(81 entries) reaches 100% on div-by-3 at N=1000 (D=40%). E(625 entries) reaches 100% on div-by-5 at N=5000 (D=62%). b(2401 entries) reaches 96.4% on div-by-7 at N=25000 (D=68.2%), CONFIRMED AT SCALE. The threshold is ~10 samples per q^2 entry. Root cause: CRT moduli are coprime -- own channel directly observes v%p, non-own channels detect only cross-channel temporal correlations. At sufficient data, each channel is the optimal detector for its own prime. The axiom's channel assignments are capacity-correct at ALL scales -- b overtakes D (482 vs 341) at exactly the predicted N~24000 threshold.

490 SPLIT BLOOM ASYMMETRY: 490-gated bloom on K-divisibility (sensor=K=ALIVE) reveals that the bloom benefit is DIRECTIONAL. When the sensor is DEAD (D, THM 260): 490-bloom lifts ALIVE +24.8%, standard bloom catastrophic (-74%). When the sensor is ALIVE (K, this result): standard bloom HELPS (+15%), 490-bloom neutral (0%). Perception channels (DEAD) process privately; strategy channels (ALIVE) coordinate publicly. Bloom is the gate from private to public. When the sensor is already public (ALIVE), additional gating is redundant or harmful.

The optimal architecture for any CRT-LM task depends on which channels carry the sensor signal.

E-CHANNEL CONDITIONAL CAPACITY: div-by-5 conditional task (add if x%5==0, multiply otherwise) -- the E-prime analog of D parity detection. E-channel (Z/25=5^2) preserves div-by-5 information: x%25 in {0,5,10,15,20} iff x%5==0. All other channels have gcd(q,5)=1, so div-by-5 distributes uniformly -- they CANNOT detect it. E achieves 100% with correct init (the conditional IS representable), but only 8.5% from CD at N=500 -- capacity-gated (625 entries, ~4 visits each). D DOMINATES at N=500 (61.5%) despite inability to detect div-by-5 because its smaller capacity (64 entries) converges faster to the majority operation (multiply, 80%). Ordering at N=500: D(123) > K(85) > L(39) > G(33) > X(24) > E(17) > b(9) -- monotonically with 1/q. At N=2000: E improves +135% (17->40), K approaches D (117 vs 109, ~1 sigma), D declines (-14). Ordering converges: K~D>L>G>E~X>b. Each channel detects its OWN prime's conditions, but larger channels need proportionally more data (~10*q^2). The parity task (THM 259, D=96%) and div-by-5 task (THM 265, E=8.5% at N=500) are the SAME mechanism at different capacity scales.

MULTI-PRIME COOPERATION: div-by-10 conditional (x%(D*E)==0 = x%2==0 AND x%5==0) is the FIRST task structurally irreducible to any single CRT channel. No single channel can resolve x%10==0 from its residue alone: D(Z/8) detects parity but not div-by-10 (even entries: 20% div-by-10, 80% not). E(Z/25) detects div-by-5 but not div-by-10 (div-by-5 entries: 50% div-by-10). All odd-modulus channels coprime to 10. Per-channel CD: 542/1400 (38.7%), D=163 (81.5%), K=138 (69.0%), E=24 (12.0%). STANDARD BLOOM BEST: 569/1400 (+27, +5.0%). 490-gated: 544 (+2, neutral). INVERSION OF THM 260: standard bloom outperforms 490 because D and E are BOTH DEAD -- 490 gating prevents the D-E cross-talk that multi-prime detection requires. Standard bloom enables D to transmit parity and E to transmit div-by-5 through reconstruction, ALIVE and DEAD channels both receive the combined signal. DEAD improvement: standard 217 vs PC 190 (+14.2%), 490 196. E gains +54% (24->37), b +567% (3->20).

MIXED DEAD+ALIVE COOPERATION: div-by-6 conditional (x%(D*K)==0 = x%2==0 AND x%3==0) COMPLETES the bloom gating policy (4th of 4 cases). D(Z/8) detects parity (DEAD). K(Z/9) detects div-by-3 (ALIVE). Neither alone resolves x%6==0 -- requires cross-split cooperation. Per-channel CD: 439/1400 (31.4%). D=131 (65.5%), K=145 (72.5%). STANDARD BLOOM BEST: 450/1400 (+11, +2.5%). 490-gated: 430 (-9, -2.1%). Standard bloom lifts DEAD 162->177 (+9.3%): E +43% (21->30), b +50% (10->15). 490 gating PRESERVES DEAD (161=162) but prevents D from contributing to the value K sees after bloom sync. COMPLETE GATING POLICY (all 4 cases): single-DEAD sensor -> 490 bloom (THM 260). Multi-DEAD cooperation -> standard bloom (THM 266). ALIVE sensor -> standard bloom (THM 262). Mixed DEAD+ALIVE -> standard bloom (THM 267). UNIVERSAL: standard bloom is the safe default for all multi-channel cooperation. 490 bloom is only superior for single-DEAD sensor tasks where one DEAD channel carries the entire signal and bloom would wash it.

K-TERNARY DETECTION: 3-way branching on x%3 (K-native structure). If x%3==0: add. If x%3==1: multiply. If x%3==2: no-op. K(Z/9) is the SOLE sensor because 3|9 -- x%9 directly reveals x%3. All other moduli {8,25,49,11,13,17} are coprime to 3, making them completely ternary-blind. RESULT: K achieves 200/200 = 100% from coordinate descent -- the first data channel to reach 100% via CD on a multi-class task (D achieved 96% on 2-way parity, THM 259; thin channels reach 100% trivially on binary conditions, THM 261). K contributes 61.9% of all test hits (200 of 323). Non-K channels near chance (3-21%). K-correct init (3-way table) also achieves 100%. BLOOM IS CATASTROPHIC: standard bloom drops K from 200 to 65 (-67.5%). 490-gated: 200 to 62 (-69%). When the dominant sensor has a perfect per-channel solution, bloom mixing only injects cross-channel noise into trained LUT entries, moving K to untrained entries. EXTENDS GATING POLICY: when a single ALIVE channel is the sole sensor AND achieves near-perfect accuracy, per-channel CD is strictly optimal -- bloom coupling trades accuracy for cross-channel coordination that is structurally unnecessary. This parallels how experts in a specific domain perform WORSE when forced to use consensus-seeking procedures that dilute their expertise.

TRIPLE-PRIME CONDITIONAL: div-by-30 (x%(D*K*E)==0) -- the FIRST 3-channel irreducible task. Requires ALL three: D detects x%2==0 (DEAD), K detects x%3==0 (ALIVE), E detects x%5==0 (DEAD). No pair suffices: D+K=div-by-6, D+E=div-by-10, K+E=div-by-15. Only the triple resolves div-by-30. STANDARD BLOOM BEST: 875/1400 (+2.5% vs PC 854) vs 490-gated 831 (-2.7%). DEAD channels lift +20% under standard bloom: E 41->70 (+71%), b 12->32 (+167%). 490-gated preserves DEAD exactly (236~=239) but blocks the D-E cross-talk AND the D,E->K information flow needed for 3-way cooperation. D(93%) and K(93%) near-perfect individually on their sub-conditions (task is 97.4% multiplicative at 2.6% div-by-30 rate). D+K+E sensor signal: 441 (BA) vs 413 (PC) vs 411 (490) -- standard bloom uniquely lifts the combined signal. CONFIRMS GATING COMPOSITION: multi-channel cooperation at ANY depth follows the same rule -- standard bloom. The gating policy tested across 5 cases (THMs 260, 262, 266, 267, 269) is now a single universal statement: standard bloom for multi-channel tasks, 490 for single-DEAD sensor, per-channel for perfect sole-sensor.

PRESERVATION DEPTH SCALING: copy task (target = first element of sequence, memory/preservation) tested at SL=5, 10, 20. PLUT is DEPTH-INVARIANT: 1400/1400 (100%) at all three sequence lengths. Position-separability makes copy completely SL-independent. 2D-LUT preserve-init degrades GRACEFULLY overall: 92.9% (SL=5) -> 91.9% (SL=10) -> 80.8% (SL=20). But the per-channel story reveals a Z/9 CATASTROPHIC COLLAPSE: K-channel drops from 93.5% (SL=5) to 89.5% (SL=10) to 10% (SL=20), a phase transition accounting for 98% of total decline (167/170 points). All other channels maintain >85% at SL=20. Large channels are depth-robust: Z/49=98%, Z/25=96.5%, Z/8=87% (unchanged from SL=5). Z/9 is observed to be fragile on preservation at depth (single seed -- multi-seed verification needed). Hypothesis: K=3 compositional bias plus moderate table size (81 entries) makes CD more likely to damage preserve-state rows. Each damaged entry propagates through 19 distractor positions (SL=20), compounding errors. EXTENDS THM 271 (Memory Barrier) to variable depth: the basin wall's impact is channel-specific, not uniform.

POSITION-CAPACITY GATING: copy n-back (target = seq[n] for n=0..4) FALSIFIES position-invariance. PLUT shows strong position gradient: n=0=100%, n=1=87%, n=2=61%, n=3=73%, n=4=34%. Small channels (Z/8, Z/11) are completely position-immune -- 100% at ALL target positions. Large channels (Z/49, Z/25) degrade sharply: Z/49 fails at n>=1 (6.5%), Z/25 fails at n>=2 (3.5%). Root cause: PLUT CD has N/q samples per entry. Z/8 has ~62 samples/entry (signal resolves), Z/49 has ~10 (CD overfits). Position 0 is PRIVILEGED: identity default is already correct for the n=0 task, so CD never disturbs it regardless of capacity. For n>0, CD must DISCOVER which position to protect, but at low samples/entry the signal is indistinguishable from noise. 2D-LUT reveals the complementary pattern: target=last-element (n=4) achieves 51% because identity-on-x is position-FREE -- correct at ALL sequence positions simultaneously. First and middle element targets remain at chance (memory barrier). CAPACITY determines both which channels learn AND which target positions are accessible.

PATTERN EXTRACTION ASYMMETRY: first ABSTRACTION task. Arithmetic sequence [v0, v0+d, v0+2d, v0+3d, v0+4d], target = common difference d. ARCHITECTURE INVERSION: 2D-LUT (53.2%) BEATS PLUT default (38.4%) -- the OPPOSITE of the copy task ordering. On copy (memory), position-awareness dominates. On pattern extraction (rule computation), state-dependence dominates. Root cause: at position 1 the 2D-LUT entry (h=v0, x=v0+d) directly DETERMINES d=(x-h)%q. 2D-LUT exploits this (h,x) pair structure. PLUT's additive model h=sum(PLUT[pos][vi%q]) faces the additive ceiling -- changing entries at one position doesn't help when others still contribute noise. PLUT correct init (PLUT[0]=-x, PLUT[1]=x, PLUT[2-4]=0) achieves 100%, proving the architecture IS sufficient. The gap is CD optimization, not capacity. LUT at 21.4% (3x chance) shows arithmetic regularity is partially extractable even without position or state. Z/9 dominates 2D-LUT at 77% -- K-channel naturally captures compositional structure. All capacity-gated: small channels 60-77% >> large channels 10-22%.

COORDINATION BARRIER: 2D-PLUT on the copy task FALSIFIES naive universality. Correct init achieves 1400/1400 (100%) and preserve init achieves 1400/1400 (100%) -- the architecture IS sufficient. But default (additive) init produces only 99/1400 (7%, chance), matching 2D-LUT additive (106). Root cause: the COORDINATION BARRIER. For copy, positions 1-4 must ALL learn preserve-state (table[h][x]=h) simultaneously. Under additive default, each entry outputs (h+x)%q. Changing ONE entry at one position to output h does not improve total accuracy because the OTHER positions still corrupt the state via continued additive chaining. CD is greedy (one entry at a time) and cannot coordinate simultaneous changes across positions. PLUT avoids this barrier entirely: its default initialization is ALL ZEROS. In the additive model h=sum(PLUT[pos][x]), zero means 'don't change state.' Positions 1-4 are already correct for copy from the start (they contribute nothing). CD only needs to set PLUT[0][x]=x -- a single-position fix. The distinction: PLUT's zero default aligns with 'preserve' (correct for copy), while 2D-PLUT's additive default (h+x)%q does not. 2D-PLUT preserve init: CD only needs to fix position 0 (table[0][x]=0 to table[0][x]=x), which is trivially learnable since h=0 always at pos 0. The lesson: 2D-PLUT IS the universal architecture when paired with task-appropriate initialization. The initialization IS the inductive bias -- memory tasks need preserve init, computation tasks work from additive default.

RANDOM INIT EQUIVALENCE: K^2=9 diverse random 2D-PLUT initializations on the copy task show that the coordination barrier is STRUCTURAL, not initialization-specific. All 9 random inits produce test accuracy indistinguishable from chance (mean 102/1400 = 7.3%, range 86-111), matching the additive default (99/1400). Preserve fraction at random: 34-37/1000 (expected 35.2/1000 = weighted 1/q average). No point in the 18750-dimensional parameter space is close enough to the preserve basin for greedy CD to amplify. The barrier requires EXPLICIT inductive bias -- task-appropriate initialization that encodes what the model should do.

EVOLUTIONARY BARRIER: multi-generation directed evolution (100 generations, K^2=9 population, elitist selection + 2% mutation) CANNOT cross the coordination barrier. From random init: pure evolution improves pre-CD score from 117 to 219 over 100 generations (+87% relative) by accumulating ad-hoc lucky entries -- but pattern fraction stays flat at 33/1000 (no systematic structure discovered). After CD training: evolved init scores only 129/1400 -- CD largely overwrites evolutionary gains (219->129) by replacing ad-hoc entries with systematic additive patterns that are wrong for copy (evolved+CD still beats default+CD 99, but far from correct 1400). From perturbed correct init (80% entries correct, 20% random): ZERO improvement over 100 generations (616/1400 stable). Selection perfectly resists drift but blind mutation cannot repair -- each random entry change has (q-1)/q > 87% chance of being wrong. CASCADE LOCK: 80% correct entries produce only 44% sequence accuracy because single wrong entries corrupt downstream state-machine chains. Neither random search (THM 278), greedy CD (THM 277), nor directed evolution (THM 279) can cross the barrier. Only EXPLICIT CONSTRUCTION works. BIOLOGY: if the brain requires coordinated CRT-like initialization, evolution must encode DEVELOPMENTAL PROGRAMS -- structured growth rules that CONSTRUCT the correct init pattern, not the init weights directly. The genome encodes rules, not tables.

DEVELOPMENTAL PROGRAMS: 5 rules (CAPTURE, PRESERVE, ADD, ZERO, SUBTRACT) compress 18750 table entries to a 5-gene genome (3750x). Exhaustive search over 3125 genomes finds optima for copy ([0,1,1,1,1]=1400/1400) and pattern extraction ([4,2,1,1,1]=1400/1400). Coordinate search (26 evals) succeeds on copy but fails on pattern -- the coordination barrier persists at the rule level (pos 0+1 must change simultaneously). Barrier dissolved only by exhaustive enumeration in the compressed space. THM 279 evolution used 900 entry-level evals and failed; rule compression makes exhaustive tractable.
