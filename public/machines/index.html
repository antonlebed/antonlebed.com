Machines and learning

What a state that grows by places can compute, remember and learn: a state that only multiplies driven by a program that reads it, registers over a pool of windows read only by asking whether they are zero, a state map read as forgetting a datum of its history, two products of polynomials that coincide, and a reader that learns a stream by exact comparisons.

  • MACHINE — a state that only multiplies, read as a machine
  • SUPPLY — the element machine over a growing supply of windows
  • FORGET — when a state provably no longer holds a datum
  • COLLIDE — when two products of weighted sets are one polynomial
  • LEARNER — a reader that learns by exact comparisons of its price
