Ring Substrate

Can ring arithmetic serve as the SOLE computation substrate? Not CRT decomposing a neural network. Not CRT as a technique. The ring IS the latent space. Every intermediate value is a ring element. Every operation is ring arithmetic. Zero floats.

This page reports the first Ring Substrate experiment: context-dependent function learning with 4 ring multiplications, evolutionary per-channel search, and ring vs random coprime control.

Architecture

All computation is ring arithmetic. No floats, no dot-product attention, no dense FFN. The ring's structure IS the machine.

ATTEND
Channel matching
coupling(context, prototype) = count of channels where ctx%q == proto%q. Replaces dot-product attention.
TRANSFORM
Ring multiplication
output_ch = (input_ch * weight_ch) % q_ch. Per-channel independence = block-diagonal for free.
SELECT
Argmax
Pick prototype with highest channel match. Route to corresponding weight.
LEARN
Per-channel evolution
Mutate one channel of one parameter. Accept if ch_score improves. 200 generations x 56 trials.

Channel Split Emerges

The model discovers a functional split without being told. Small-modulus channels (mod 9, mod 11, mod 13) dominate attention. Large-modulus channels (mod 8, mod 25, mod 49) are weaker discriminators. The split: small = routing/selection, large = data/perception.

Interpretation

Ring substrate learning is VIABLE. All computation was ring arithmetic: integer modular operations for attention, multiplication for FFN, greedy per-channel search for learning. The paradigm works.

The ring does not strongly outperform random coprimes on per-channel accuracy (-1.3% ch_score). But it has 27% better exact match: when the ring is right, it is right everywhere; when wrong, wrong everywhere. This coherence is a structural property of the specific channel sizes and their algebraic relationships.

The channel split emerging in attention is the key finding. The model discovered that smaller-modulus channels (9, 11, 13) are better for routing, while larger-modulus channels (8, 25, 49) carry information. Not designed, DISCOVERED.
