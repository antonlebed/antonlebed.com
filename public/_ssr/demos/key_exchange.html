CRT Key Exchange

RSA/Certicom patents. CC0 alternative.

Diffie-Hellman key exchange runs in parallel across 7 CRT channels. Each channel uses its own primitive root as generator. 7 small discrete-log problems instead of 1 big one. CRT reconstructs the shared secret from 7 channel agreements.

How It Works

CRT Diffie-Hellman
Classic DH: g^a mod p (one big modulus). CRT DH: g_i^a mod m_i for each channel (7 small moduli). Alice sends 7 public residues. Bob sends 7. Each computes 7 shared residues independently. CRT reconstruction gives the unique shared secret in Z/214,414,200.
7 generators
Primitive roots
Each channel has its own generator: {3,2,2,3,2,2,3}.
Parallel exchange
CRT independence
7 small key exchanges run independently.
Shared secret
CRT reconstruction
7 channel agreements -> unique shared value.
Channel security
Discrete log per mod
Breaking one channel reveals only 3-6 bits.

CRT-Native: ~60 Lines to 10 Lines

Language Revolution
With crt_mode(1), the .ax compiler decomposes * into 7 per-channel CRT operations. Binary exponentiation becomes per-channel powmod AUTOMATICALLY. One call to crt_kex_pow replaces 7 manual powmod calls per party. No mulmod needed. The compiler handles overflow.
