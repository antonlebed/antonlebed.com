CRT Image Filter

Z/214,414,200 = Z/8 x Z/9 x Z/25 x Z/49 x Z/11 x Z/13 x Z/17

Decompose each pixel into 7 independent CRT channels. Filter each channel separately -- no cross-channel bleed. The mod-11 channel detects single-channel corruption for free.

How It Works

Every pixel value (0-255) lives in Z/214,414,200. The Chinese Remainder Theorem splits this into 7 independent channels: mod 8, mod 9, mod 25, mod 49, mod 11, mod 13, mod 17.

Filter each channel separately -- no cross-channel artifacts. Reconstruct with CRT to get the filtered pixel.

The mod-11 channel serves as an integrity check. Corrupt the mod-49 channel? A parity prediction from the other 6 channels detects ~92% of single-channel errors.
