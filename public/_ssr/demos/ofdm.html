CRT-OFDM

OFDM patents. CC0 alternative.

CRT approach to OFDM modulation. Each of 7 channels carries an independent PSK constellation: 8-PSK, 9-PSK, 25-PSK, 49-PSK, 11-PSK, 13-PSK, 17-PSK. Theoretical capacity: 27 bits per symbol over 7 subcarriers = 3.86 bits/subcarrier vs WiFi 802.11a BPSK rate-1/2 at 0.50 bits/subcarrier (ideal channel, no noise).

How It Works

CRT-OFDM Principle
A data symbol d in Z/214,414,200 decomposes into 7 residues. Each residue modulates a subcarrier using p-ary PSK (phase angle = 2*pi*r/m for residue r and modulus m). The receiver demodulates each subcarrier independently (nearest constellation point), then CRT reconstructs the original symbol. Channel independence: noise in one subcarrier cannot corrupt another. 3 data subcarriers + 4 parity subcarriers provide built-in error detection.
