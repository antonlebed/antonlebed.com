CRT Hash

Crypto hash patents. CC0 alternative.

CRT decomposition IS a hash function. Decompose into 7 independent channels, mix per-channel with primitive roots, fold through CRT reconstruction. 8 rounds. Pure ring arithmetic. No XOR, no bit shifts, no lookup tables.

How It Works

CRT Hash Principle
Every integer has a UNIQUE 7-dimensional CRT address in Z/8 x Z/9 x Z/25 x Z/49 x Z/11 x Z/13 x Z/17. Per-channel mixing with generators {3,2,2,3,2,2,3} creates nonlinearity. Cross-channel addition creates diffusion. CRT reconstruction folds channels back. After 8 rounds, no channel remembers the input alone.
7 parallel lanes
CRT decomposition
7 independent mixing networks. Each uses a different primitive root.
Cross diffusion
Neighbor injection
Each channel absorbs 2 neighbors per round. After 3 rounds, every channel influenced by every other.
CRT fold
Bijection breaker
Reconstruct to integer, multiply by 137, re-decompose.
8 rounds
Full diffusion
By round 8, each output depends on every input. Natural from algebraic independence.

Bit-Level Avalanche Benchmark

Channel avalanche (above) measures how many CRT channels change. Bit-level avalanche measures how many individual bits flip in the output. SHA-256 ideal: ~50% of 256 bits. CRT hash ideal: 50% of ~28 bits = 14.0 bits.

CRT-Native: ~45 Lines to 6 Lines

Language Revolution
With crt_mode(1), the .ax compiler automatically decomposes * and + into 7 per-channel CRT operations. A ring hash becomes pure algebra: multiply, add, iterate. No manual % 8, % 9. No idempotent reconstruction. No mulmod to avoid overflow. The CRT structure lives in the TYPE, not the CODE.
Old: ~45 lines
Manual CRT
Explicit % 8, % 9, ... % 17. Explicit idempotent array. mulmod for each channel. 7-channel Feistel with cross-channel mixing by hand.
New: 6 lines
CRT-native
fn crt_hash(n) = ( mut x = n*29+1; while rd<8 do x=x*29+rd*43+n ). Ring arithmetic. Period.
