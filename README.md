# antonlebed.com

Numbers read one place at a time.

This repository is the site served at <https://antonlebed.com>.
`public/` is the site exactly as served: every page, every script with
a page of its own (under `public/code/`) and the raw docs beside their
pages; the home page, `public/index.html`, is the index. `worker.js` is the
router and `wrangler.jsonc` its configuration.
